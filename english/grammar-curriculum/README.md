# 영어 교육 커리큘럼: 한일 교수 방법론 기반

> 세무 도메인 백엔드 개발자를 위한 14주 영어 문법 커리큘럼

## 교육 철학

한일 교수의 핵심 교육 원칙을 기반으로 설계:

1. **WHY-first**: 문법 용어가 생겨난 이유와 배경을 먼저 설명
2. **최소 문장 → 확장**: 가장 작은 문장에서 차근차근 확장
3. **영어식 사고 체득**: 핵심 먼저 → 꼬리 붙이기 (SVO 사고 흐름)
4. **문법 = 글쓰기 도구**: 독립 지식이 아닌 실제 문장 생산 도구
5. **프로그래밍 비유 적극 활용**: 개발자의 사고체계를 레버리지

## 매 Lesson 구조

모든 Lesson은 동일한 6단계 구조를 따름:

```
1. WHY     — 이 문법이 왜 존재하는지 배경/원리 설명
2. CORE    — 핵심 개념을 가장 짧은 문장으로 체득
3. EXPAND  — 짧은 문장 → 긴 문장으로 확장
4. CODE    — 개발자 비유로 재이해 (프로그래밍 개념 매핑)
5. DOMAIN  — 세무/기술 도메인 실제 예문
6. PRACTICE — 문장 만들기 연습 (빈칸/작문)
```
