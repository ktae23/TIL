# 부가가치세 기초 (VAT Basics)

> 📚 **선수 지식**: [세금의 종류와 체계](./tax-system-overview.md), [분개와 전기](./journal-entries.md)

## 부가가치세란 무엇인가

부가가치세 (Value Added Tax, VAT)는 재화 (Goods)나 용역 (Services)이 생산·유통되는 각 단계에서 창출되는 부가가치 (Added Value)에 대해 부과하는 세금이다. 한국의 부가가치세율은 **10%**로 단일 세율을 적용한다.

### 부가가치의 의미

부가가치란 기업이 생산 과정에서 새롭게 창출한 가치를 말한다. 간단히 말해 **매출액에서 매입액을 뺀 금액**이 부가가치이다.

```
부가가치 = 매출액 (Sales) - 매입액 (Purchases)
```

예를 들어, 원재료를 5,000원에 매입하여 완성품을 10,000원에 판매했다면, 이 기업이 창출한 부가가치는 5,000원이며, 이에 대한 부가가치세는 500원이다.

### 부가가치세의 특징

1. **간접세 (Indirect Tax)**: 사업자가 납부하지만 최종 소비자 (End Consumer)가 실제 부담
2. **다단계 과세 (Multi-stage Taxation)**: 생산·유통의 각 단계에서 부과
3. **전단계 세액공제법 (Input Tax Credit Method)**: 매출세액에서 매입세액을 빼는 방식으로 이중 과세 방지
4. **역진성 (Regressivity)**: 소득에 관계없이 동일한 세율이 적용되어 저소득층에 상대적으로 불리
5. **세수 확보 효과**: 거래 단계마다 세금계산서가 발행되므로 탈세 방지 효과

### 부가가치세의 과세 원리 (전단계 세액공제법)

유통 과정에서 부가가치세가 어떻게 작동하는지 예를 들어 살펴보자.

| 단계 | 거래 금액 | 부가가치 | 매출세액 | 매입세액 | 납부세액 |
|------|-----------|----------|----------|----------|----------|
| 원재료 생산자 → 제조업자 | 1,000원 | 1,000원 | 100원 | 0원 | 100원 |
| 제조업자 → 도매업자 | 3,000원 | 2,000원 | 300원 | 100원 | 200원 |
| 도매업자 → 소매업자 | 5,000원 | 2,000원 | 500원 | 300원 | 200원 |
| 소매업자 → 소비자 | 8,000원 | 3,000원 | 800원 | 500원 | 300원 |
| **합계** | - | **8,000원** | - | - | **800원** |

최종 소비자가 부담하는 부가가치세 총액 800원 (= 8,000원 × 10%)이 각 단계의 사업자를 통해 나누어 납부된다. 이것이 **전단계 세액공제법 (Invoice Method)**의 핵심이다.

## 과세사업자와 면세사업자

### 과세사업자 (Taxable Business)

재화·용역을 공급하고 부가가치세를 징수·납부할 의무가 있는 사업자이다. 대부분의 사업자가 여기에 해당한다.

- 세금계산서 (Tax Invoice) 발행 의무
- 매입세액 공제 (Input Tax Credit) 가능
- 부가가치세 신고·납부 의무

### 면세사업자 (Tax-exempt Business)

특정 재화·용역의 공급에 대해 부가가치세가 면제되는 사업자이다. 주로 국민 생활 필수품이나 공익적 성격의 용역에 적용된다.

**면세 대상:**
- 기초 생활필수 식료품 (미가공 농·축·수·임산물)
- 수돗물
- 연탄, 무연탄
- 의료·보건 용역
- 교육 용역
- 도서, 신문, 잡지
- 여객운송 (시내버스, 지하철 등)
- 금융·보험 용역
- 주택 임대

면세사업자는:
- 세금계산서 대신 **계산서 (Invoice)** 발행
- 매입세액 공제 불가 (매입 부가세가 원가에 포함됨)
- 부가가치세 신고 의무 없음 (대신 사업장 현황 신고)

### 과세·면세 겸영 사업자

하나의 사업자가 과세 사업과 면세 사업을 동시에 영위하는 경우, 겸영 사업자 (Mixed Supply Business)가 된다. 이 경우 공통 매입세액 (Common Input Tax)의 안분 계산이 필요하다.

```
공제 가능 매입세액 = 공통 매입세액 × (과세 매출 / 총 매출)
```

## 일반과세자와 간이과세자

과세사업자는 매출 규모에 따라 일반과세자 (General Taxpayer)와 간이과세자 (Simplified Taxpayer)로 구분된다.

### 일반과세자 (General Taxpayer)

| 항목 | 내용 |
|------|------|
| 기준 | 연 매출 8,000만원 이상 |
| 세율 | 10% (공급가액 기준) |
| 세금계산서 | 발행 의무 있음 |
| 매입세액 공제 | 전액 공제 가능 |
| 납부세액 | 매출세액 - 매입세액 |
| 신고 주기 | 연 2회 (예정 + 확정) |

### 간이과세자 (Simplified Taxpayer)

| 항목 | 내용 |
|------|------|
| 기준 | 연 매출 8,000만원 미만 |
| 세율 | 업종별 부가가치율 (15~40%) × 10% |
| 세금계산서 | 발행 의무 없음 (영수증 발행) |
| 매입세액 공제 | 매입액 × 업종별 부가가치율 × 0.5% |
| 납부세액 | 매출액 × 업종별 부가가치율 × 10% - 공제세액 |
| 신고 주기 | 연 1회 (1월 확정신고) |

### 간이과세자 업종별 부가가치율

| 업종 | 부가가치율 |
|------|-----------|
| 소매업, 재생재료수집판매업 | 15% |
| 제조업, 농·임·어업, 소화물전문운송업 | 20% |
| 음식점업 | 25% |
| 건설업, 운수·통신업 | 30% |
| 금융·보험·서비스업 | 40% |
| 부동산임대업 | 40% |

### 간이과세자 → 일반과세자 전환

연 매출이 8,000만원 이상이 되면 다음 해 7월 1일부터 일반과세자로 전환된다. 반대로 일반과세자의 매출이 기준 미만으로 떨어지면 간이과세자로 전환될 수 있다. 다만, 다음의 경우에는 간이과세가 배제된다:

- 광업, 제조업 (일부), 도매업
- 부동산매매업
- 간이과세 배제 지역의 사업장
- 둘 이상의 사업장이 있는 경우 합산 매출 기준 적용

## 매출세액과 매입세액

### 매출세액 (Output VAT)

사업자가 재화·용역을 공급할 때 거래 상대방으로부터 징수하는 부가가치세이다.

```
매출세액 = 공급가액 (Supply Value) × 10%
```

예: 100,000원짜리 상품 판매 시
- 공급가액: 100,000원
- 매출세액: 10,000원
- 거래 총액: 110,000원 (공급가액 + 부가가치세)

### 매입세액 (Input VAT)

사업자가 재화·용역을 공급받을 때 거래 상대방에게 지급하는 부가가치세이다. 이 금액은 납부세액 계산 시 매출세액에서 공제된다.

### 납부세액 계산

```
납부세액 = 매출세액 - 매입세액

매출세액 > 매입세액 → 납부 (Tax Payable)
매출세액 < 매입세액 → 환급 (Tax Refund)
```

### 매입세액 불공제 항목

다음의 매입세액은 공제받을 수 없다:

1. **세금계산서 미수취 또는 부실 기재**: 적격 세금계산서가 없는 경우
2. **사업과 직접 관련 없는 지출**: 개인적 용도의 지출
3. **접대비 관련 매입세액**: 접대비 (Entertainment Expense)에 대한 부가세
4. **비영업용 소형승용차 구입·유지 관련 매입세액**: 업무용이 아닌 승용차
5. **토지 관련 매입세액**: 토지의 취득·조성 관련 지출
6. **면세 사업 관련 매입세액**: 면세 매출에 대응하는 매입
7. **사업자등록 전 매입세액**: 사업자등록 신청일로부터 역산 20일 전의 매입은 불공제

## 세금계산서 (Tax Invoice)

세금계산서는 부가가치세 과세 거래의 증빙 서류로, 매입세액 공제의 핵심 근거 자료이다.

### 세금계산서의 필수 기재사항

1. 공급자의 등록번호, 성명 또는 명칭
2. 공급받는 자의 등록번호
3. 공급가액과 부가가치세액
4. 작성 연월일

### 세금계산서의 종류

| 종류 | 설명 |
|------|------|
| 세금계산서 (Tax Invoice) | 과세사업자가 발행하는 부가세 포함 증빙 |
| 계산서 (Invoice) | 면세사업자가 발행하는 증빙 (부가세 없음) |
| 영수증 (Receipt) | 소비자 대상 거래 시 발행 |
| 신용카드 매출전표 | 세금계산서와 동일한 효력 (매입세액 공제 가능) |

### 전자세금계산서 (Electronic Tax Invoice, e-Tax Invoice)

법인사업자와 직전 연도 공급가액 합계 8,000만원 이상인 개인사업자는 **전자세금계산서** 발행이 의무이다.

- 발행 기한: 공급 시기가 속하는 달의 **다음 달 10일**까지
- 전송: 발행일 다음 날까지 국세청 전송
- 미발행 가산세: 공급가액의 2%
- 지연 발행 가산세: 공급가액의 1%
- 지연 전송 가산세: 공급가액의 0.5%

## 신고·납부 주기

부가가치세는 **1년을 2개의 과세기간 (Tax Period)**으로 나누어 신고·납부한다.

### 과세기간과 신고 일정

| 구분 | 과세기간 | 예정신고 | 확정신고 |
|------|----------|----------|----------|
| 제1기 | 1월 1일 ~ 6월 30일 | 4월 25일까지 (1~3월분) | 7월 25일까지 (1~6월분) |
| 제2기 | 7월 1일 ~ 12월 31일 | 10월 25일까지 (7~9월분) | 다음 해 1월 25일까지 (7~12월분) |

### 예정신고 (Preliminary Return)

과세기간의 전반기 3개월분에 대해 중간에 신고·납부하는 것이다.

- **법인사업자**: 예정신고 의무 (직접 신고·납부)
- **개인사업자**: 예정고지 (국세청이 직전 확정신고세액의 50%를 고지)
  - 단, 휴업·사업부진 등의 사유가 있으면 예정신고 가능

### 확정신고 (Final Return)

과세기간 전체(6개월)에 대해 최종 신고·납부하는 것이다. 예정신고 시 납부한 세액은 확정신고 시 기납부세액으로 차감한다.

```
확정 납부세액 = 확정 매출세액 - 확정 매입세액 - 예정신고 납부세액
```

### 신고 기한 연장

천재지변, 화재 등 부득이한 사유가 있는 경우 관할 세무서장에게 기한 연장을 신청할 수 있다.

## 영세율과 면세

영세율 (Zero-rate)과 면세 (Exemption)는 모두 부가가치세를 부담하지 않는다는 점에서 비슷하지만, 그 효과는 크게 다르다.

### 영세율 (Zero-rate)

세율이 0%인 것이다. 과세 거래이지만 세율이 0%이므로 매출세액이 0원이 된다. 그러나 **과세 거래**이므로 매입세액 공제는 가능하다.

```
매출세액 = 공급가액 × 0% = 0원
납부세액 = 0원 - 매입세액 = 환급 (Refund)
```

**영세율 적용 대상:**
- 수출하는 재화 (Export Goods)
- 국외에서 제공하는 용역 (Services Supplied Abroad)
- 선박·항공기의 외국 항행 용역
- 외국인 관광객에 대한 일정 물품 판매
- 외화 획득 재화·용역

영세율은 수출 촉진을 위한 제도로, 수출 기업은 국내 매입 시 부담한 부가가치세를 전액 환급받을 수 있다.

### 면세 (Exemption)

부가가치세가 면제되는 것이다. 면세 거래는 **비과세 거래**이므로 매출세액도 없고, 관련 매입세액 공제도 불가능하다.

```
매출세액 = 없음 (과세 거래 아님)
매입세액 공제 = 불가능
```

면세 사업자의 매입 부가가치세는 원가에 포함된다.

### 영세율 vs 면세 비교

| 구분 | 영세율 (Zero-rate) | 면세 (Exemption) |
|------|-------------------|------------------|
| 세율 | 0% | 해당 없음 (비과세) |
| 과세 여부 | 과세 거래 | 비과세 거래 |
| 매입세액 공제 | 가능 (전액 환급) | 불가능 (원가 포함) |
| 세금계산서 | 영세율 세금계산서 발행 | 계산서 발행 |
| 목적 | 수출 촉진 | 생필품·공익 서비스 보호 |
| 사업자 입장 | 유리 (환급 가능) | 불리할 수 있음 (매입세액 불공제) |

## 부가세 신고서 주요 항목

부가가치세 신고서 (VAT Return Form)의 주요 항목을 살펴보자.

### 매출 관련 항목

| 항목 | 설명 |
|------|------|
| 과세 매출 (세금계산서 발급분) | 세금계산서를 발급한 과세 매출 |
| 과세 매출 (매출처별세금계산서합계표 기재분) | 세금계산서 합계 |
| 과세 매출 (신용카드·현금영수증 발행분) | 카드·현금영수증 매출 |
| 과세 매출 (기타) | 위에 해당하지 않는 과세 매출 |
| 영세율 매출 (세금계산서 발급분) | 영세율 세금계산서 발급 매출 |
| 영세율 매출 (기타) | 기타 영세율 매출 |

### 매입 관련 항목

| 항목 | 설명 |
|------|------|
| 세금계산서 수취분 (일반매입) | 일반 세금계산서 수취 매입 |
| 세금계산서 수취분 (고정자산매입) | 고정자산 (Fixed Asset) 취득 관련 매입 |
| 기타 공제 매입세액 | 신용카드, 의제매입세액 등 |
| 공제받지 못할 매입세액 | 불공제 항목 (접대비, 비업무용 차량 등) |

### 세액 계산 구조

```
① 매출세액 합계
② (-) 매입세액 합계
③ (=) 차감 납부(환급)세액
④ (-) 예정신고 납부세액
⑤ (-) 예정고지세액
⑥ (+) 가산세 (Penalty Tax)
⑦ (=) 최종 납부(환급)세액
```

### 가산세 (Penalty Tax)

부가가치세 관련 주요 가산세는 다음과 같다.

| 유형 | 가산세율 |
|------|----------|
| 무신고 (Non-filing) | 납부세액의 20% (부당 40%) |
| 과소신고 (Under-reporting) | 과소신고 납부세액의 10% (부당 40%) |
| 납부불성실 (Late Payment) | 미납세액 × 0.022% × 경과일수 |
| 세금계산서 미발급 | 공급가액의 2% |
| 세금계산서 지연발급 | 공급가액의 1% |
| 매출처별세금계산서합계표 미제출 | 공급가액의 0.5% |

## 부가가치세 회계 처리

### 매출 시 분개

상품 100,000원을 판매하고 부가가치세 10,000원을 포함하여 총 110,000원을 받은 경우:

```
(차변) 현금 (Cash)           110,000원
  (대변) 매출 (Sales)                    100,000원
  (대변) 부가세 예수금 (VAT Payable)      10,000원
```

### 매입 시 분개

상품 50,000원을 매입하고 부가가치세 5,000원을 포함하여 총 55,000원을 지급한 경우:

```
(차변) 매입 (Purchases)       50,000원
(차변) 부가세 대급금 (VAT Receivable)  5,000원
  (대변) 현금 (Cash)                     55,000원
```

### 신고·납부 시 분개

부가세 신고 시 납부세액 5,000원 (= 매출세액 10,000원 - 매입세액 5,000원):

```
(차변) 부가세 예수금 (VAT Payable)    10,000원
  (대변) 부가세 대급금 (VAT Receivable)        5,000원
  (대변) 현금 (Cash)                           5,000원
```

## 개발자가 알아야 할 것 (What Developers Need to Know)

### 시스템 설계 시 고려 사항

1. **공급가액과 부가세 분리 저장**: 모든 거래 금액을 공급가액 (Supply Value)과 부가가치세액 (VAT Amount)으로 분리 저장해야 한다. 부가세 포함 총액 (Total Amount)만 저장하면 세금 신고 시 계산이 복잡해진다.

2. **과세·면세·영세율 구분**: 상품·서비스마다 과세 유형 (Taxable, Exempt, Zero-rated)을 관리해야 한다. 이 구분이 매입세액 공제 여부와 신고서 작성에 직접 영향을 미친다.

3. **세금계산서 전자 발행 연동**: 전자세금계산서 발행 의무가 있는 사업자를 위해 국세청 e-세로 (e-Sero) 시스템 또는 ASP (Application Service Provider) 연동이 필요하다. 표준전자세금계산서 XML 스키마를 준수해야 한다.

4. **신고 기간별 집계**: 과세기간 (1기/2기), 예정/확정 신고 구분에 따른 매출·매입 집계가 필요하다. 날짜 기준이 아닌 **공급 시기 (Time of Supply)** 기준으로 집계해야 한다.

5. **겸영 사업자의 안분 계산**: 과세·면세 매출이 동시에 있는 경우 공통 매입세액의 안분 (Apportionment) 로직이 필요하다.

6. **간이과세자 지원**: 간이과세자는 업종별 부가가치율을 적용하는 별도 계산 로직이 필요하다. 일반과세자와 간이과세자 전환 시 재고납부세액 등의 정산 로직도 고려해야 한다.

### 데이터 모델링 포인트

```
VATTransaction (부가세 거래)
├── transaction_id (거래 ID)
├── transaction_type (매출/매입)
├── tax_type (과세/면세/영세율)
├── supply_value (공급가액)
├── vat_amount (부가세액)
├── total_amount (합계금액)
├── supply_date (공급일자)
├── tax_period (과세기간: 1기/2기)
├── return_type (예정/확정)
├── tax_invoice_id (세금계산서 번호)
└── is_deductible (매입세액 공제 여부)

TaxInvoice (세금계산서)
├── invoice_id (세금계산서 번호)
├── issue_date (발행일)

├── supply_value (공급가액)
```

## 용어 사전 (Glossary)

| 한글 | 영문 | 설명 |
|------|------|------|
| 부가가치세 | Value Added Tax (VAT) | 재화·용역의 부가가치에 부과하는 간접세 |
| 매출세액 | Output VAT | 매출 시 거래 상대방에게 징수하는 부가세 |
| 매입세액 | Input VAT | 매입 시 거래 상대방에게 지급하는 부가세 |
| 공급가액 | Supply Value | 부가가치세를 제외한 거래 금액 |
| 세금계산서 | Tax Invoice | 부가세 과세 거래의 법적 증빙 서류 |
| 전자세금계산서 | Electronic Tax Invoice | 전자적 방식으로 발행·전송하는 세금계산서 |
| 과세사업자 | Taxable Business | 부가세 납부 의무가 있는 사업자 |
| 면세사업자 | Tax-exempt Business | 부가세가 면제되는 사업자 |
| 일반과세자 | General Taxpayer | 연 매출 8,000만원 이상 과세사업자 |
| 간이과세자 | Simplified Taxpayer | 연 매출 8,000만원 미만 소규모 사업자 |
| 영세율 | Zero-rate | 세율 0% 적용 (매입세액 공제 가능) |
| 면세 | Exemption | 부가세 비과세 (매입세액 공제 불가) |
| 예정신고 | Preliminary Return | 과세기간 전반기 3개월분 중간 신고 |
| 확정신고 | Final Return | 과세기간 전체 6개월분 최종 신고 |
| 부가세 예수금 | VAT Payable | 매출세액을 기록하는 부채 계정 |
| 부가세 대급금 | VAT Receivable | 매입세액을 기록하는 자산 계정 |
