# 원천징수 실무 (Withholding Tax)

> 📚 **선수 지식**: [세금의 종류와 체계](./08-tax-system-overview.md)

## 원천징수란 무엇인가

원천징수 (Withholding Tax)란 소득을 지급하는 자(원천징수 의무자)가 소득을 지급할 때 세금을 미리 징수하여 국가에 납부하는 제도이다. 소득을 받는 사람이 직접 세금을 신고·납부하는 것이 아니라, 소득을 지급하는 측에서 대신 세금을 떼어 납부하는 것이다.

### 원천징수의 목적

1. **조세 수입의 조기 확보**: 연 1회 확정신고를 기다리지 않고, 소득 발생 시점에서 즉시 세금을 징수하여 국가 재정을 안정적으로 확보
2. **납세 편의 제공**: 소득자가 직접 신고·납부하는 번거로움을 줄여줌
3. **탈세 방지**: 소득 지급 단계에서 세금을 징수하므로 소득 파악과 세금 징수가 동시에 이루어짐
4. **세부담 분산**: 소득이 발생할 때마다 조금씩 세금을 납부하므로 일시적인 세금 부담을 분산

### 원천징수의 법적 근거

원천징수는 소득세법 (Income Tax Act) 제127조~제156조, 법인세법 (Corporate Tax Act) 제73조~제74조에 근거한다. 원천징수 의무를 이행하지 않으면 가산세 (Penalty Tax)가 부과되므로 사업자에게 매우 중요한 의무이다.

## 원천징수 의무자와 납세의무자

### 원천징수 의무자 (Withholding Agent)

소득을 지급하는 자로서, 소득 지급 시 세금을 징수하여 국가에 납부할 의무가 있는 자이다.

**원천징수 의무자의 범위:**
- 국내에서 거주자·비거주자·법인에게 원천징수 대상 소득을 지급하는 자
- 법인, 개인사업자, 비영리법인, 국가·지방자치단체
- 일부 경우 개인도 원천징수 의무자가 될 수 있음 (가사 사용인 제외)

**원천징수 의무자의 의무:**
1. 소득 지급 시 세금 징수
2. 징수한 세금을 기한 내 납부
3. 원천징수이행상황신고서 제출
4. 지급명세서 제출
5. 원천징수 영수증 교부

### 납세의무자 (Taxpayer)

소득을 지급받는 자로서, 실질적으로 세금을 부담하는 자이다. 원천징수된 세금은 해당 소득자의 확정신고 시 기납부세액 (Prepaid Tax)으로 공제된다.

### 원천징수의 흐름

```
[소득 지급자]                    [소득 수령자]
(원천징수 의무자)                (납세의무자)
      │                              │
      │ ① 소득 지급 (세금 차감)      │
      │─────────────────────────────→│
      │                              │
      │ ② 원천징수 세금 납부          │
      │─────────→ [국세청]           │
      │                              │
      │ ③ 원천징수 영수증 교부        │
      │─────────────────────────────→│
      │                              │
      │           ④ 확정신고 시 기납부세액 공제
      │            [국세청] ←─────────│
```

## 원천징수 대상 소득

### 근로소득 (Employment Income)

근로의 제공으로 받는 봉급, 급여, 상여, 수당 등 모든 대가를 말한다.

**원천징수 방법:**
- **간이세액표 (Simplified Tax Table)** 적용
- 매월 급여를 지급할 때 간이세액표에 따른 세액을 원천징수
- 간이세액표는 월급여액과 공제대상 부양가족 수에 따라 결정
- 선택 비율: 간이세액의 80%, 100%, 120% 중 근로자가 선택 가능

**간이세액표 적용 예시:**

| 월급여 (비과세 제외) | 부양가족 1인 | 부양가족 2인 | 부양가족 3인 |
|----------------------|-------------|-------------|-------------|
| 200만원 | 약 19,520원 | 약 10,630원 | 약 4,510원 |
| 300만원 | 약 72,190원 | 약 51,200원 | 약 38,790원 |
| 400만원 | 약 152,950원 | 약 118,490원 | 약 96,380원 |
| 500만원 | 약 275,990원 | 약 225,480원 | 약 186,340원 |

(위 수치는 예시이며, 실제 금액은 국세청 간이세액표 참조)

**근로소득의 비과세 항목 (주요):**
- 식대: 월 20만원 이내
- 자가운전보조금: 월 20만원 이내
- 출산·보육수당: 월 10만원 이내 (6세 이하 자녀)
- 연구활동비: 월 20만원 이내
- 국외근로소득: 월 100만원 (일부 300만원) 이내

### 사업소득 (Business Income)

개인이 독립적으로 사업을 영위하여 얻는 소득이다. 프리랜서 (Freelancer) 소득이 대표적이다.

**원천징수 세율: 3.3%** (소득세 3% + 지방소득세 0.3%)

이 세율은 다음 소득에 적용된다:
- 프리랜서 용역 수수료
- 인적 용역 소득 (강사료, 원고료 등 사업소득에 해당하는 경우)
- 봉사료 수입

**계산 예시:**
```
프리랜서에게 100만원 지급 시:
  원천징수 소득세: 1,000,000 × 3% = 30,000원
  원천징수 지방소득세: 30,000 × 10% = 3,000원
  총 원천징수액: 33,000원
  실수령액: 967,000원
```

사업소득자는 다음 해 5월 종합소득세 확정신고 시 원천징수된 세액을 기납부세액으로 공제받는다.

### 기타소득 (Other Income)

일시적·비반복적으로 발생하는 소득으로, 상금, 강연료, 원고료 등이 해당한다.

**원천징수 방법:**
```
기타소득금액 = 총수입금액 - 필요경비 (Necessary Expenses)
원천징수세액 = 기타소득금액 × 20% (소득세)
지방소득세 = 원천징수세액 × 10%
```

**필요경비 인정 비율:**
| 소득 유형 | 필요경비율 |
|-----------|-----------|
| 강연료, 원고료, 인세 | 60% (단, 실제 경비가 더 크면 실제 경비) |
| 상금, 현상금, 포상금 | 80% |
| 복권 당첨금 | 없음 (필요경비 0%) |
| 서화·골동품 양도 | 80~90% |

**계산 예시 (강연료):**
```
강연료 100만원 지급 시:
  필요경비: 1,000,000 × 60% = 600,000원
  기타소득금액: 1,000,000 - 600,000 = 400,000원
  원천징수 소득세: 400,000 × 20% = 80,000원
  원천징수 지방소득세: 80,000 × 10% = 8,000원
  총 원천징수액: 88,000원
  실수령액: 912,000원
```

기타소득금액이 건별 5만원 이하이면 원천징수를 하지 않으며, 연간 기타소득금액 합계가 300만원 이하이면 종합소득에 합산하지 않고 분리과세 (Separate Taxation)로 끝낼 수 있다.

### 이자소득 (Interest Income)

예금이자, 채권이자 등 금전의 사용 대가로 받는 소득이다.

**원천징수 세율:**
| 소득 유형 | 세율 |
|-----------|------|
| 일반 이자소득 | 14% (소득세) + 1.4% (지방소득세) = 15.4% |
| 비실명 이자소득 | 42% (소득세) + 4.2% (지방소득세) = 46.2% |
| 비영업대금의 이익 | 25% (소득세) + 2.5% (지방소득세) = 27.5% |

이자소득과 배당소득의 합계가 연 2,000만원을 초과하면 금융소득 종합과세 (Comprehensive Taxation of Financial Income)가 적용되어 다른 소득과 합산하여 누진세율로 과세된다.

### 배당소득 (Dividend Income)

주식의 이익배당, 출자에 대한 배당 등을 말한다.

**원천징수 세율:**
| 소득 유형 | 세율 |
|-----------|------|
| 일반 배당소득 | 14% (소득세) + 1.4% (지방소득세) = 15.4% |
| 비실명 배당소득 | 42% (소득세) + 4.2% (지방소득세) = 46.2% |

배당소득에는 **이중과세 조정 (Dividend Tax Credit)** 제도가 있다. 법인세를 이미 납부한 법인의 이익에서 다시 배당소득세를 과세하는 이중과세를 조정하기 위해, Gross-up 방식으로 배당세액공제를 적용한다.

### 퇴직소득 (Retirement Income)

퇴직 시 받는 퇴직급여, 퇴직연금 등을 말한다.

**원천징수 방법:**
퇴직소득은 별도의 산식에 의해 세액을 계산한다. 근속연수 (Years of Service)에 따른 공제를 적용하여 장기 근속자에게 유리하도록 설계되어 있다.

```
① 퇴직급여액
② (-) 퇴직소득공제
     - 근속연수공제: 근속연수에 따라 차등
     - 환산급여공제
③ (=) 퇴직소득 과세표준
④ (×) 기본세율 (6~45%) → 산출세액
⑤ 산출세액 × (12 / 근속연수) = 연평균 산출세액
⑥ 연평균 산출세액 × 근속연수 = 퇴직소득 산출세액
```

근속연수공제:
| 근속연수 | 공제액 |
|----------|--------|
| 5년 이하 | 100만원 × 근속연수 |
| 5년 초과 ~ 10년 이하 | 500만원 + 200만원 × (근속연수 - 5) |
| 10년 초과 ~ 20년 이하 | 1,500만원 + 250만원 × (근속연수 - 10) |
| 20년 초과 | 4,000만원 + 300만원 × (근속연수 - 20) |

## 원천징수이행상황신고서 (Monthly Withholding Tax Return)

원천징수이행상황신고서는 원천징수 의무자가 매월 징수한 세금의 내역을 세무서에 신고하는 서류이다.

### 신고서 주요 기재 항목

| 구분 | 기재 내용 |
|------|-----------|
| 소득 구분 | 근로소득, 사업소득, 기타소득, 이자소득, 배당소득, 퇴직소득 등 |
| 인원 | 소득별 지급 인원 수 |
| 총지급액 | 소득별 총 지급 금액 |

| 지방소득세 | 소득별 원천징수한 지방소득세 합계 |
| 농어촌특별세 | 해당 시 기재 |
| 환급세액 | 연말정산 등으로 인한 환급액 |

## 신고·납부 절차

### 매월 납부

원천징수한 세금은 원칙적으로 **징수일이 속하는 달의 다음 달 10일**까지 납부해야 한다.

```
예: 3월분 급여에서 원천징수한 세금 → 4월 10일까지 납부
```

납부 방법:
1. **홈택스 (Hometax)**: 전자 신고·납부
2. **인터넷 뱅킹**: 전자납부번호로 납부
3. **은행 창구**: 납부서 직접 제출

### 반기별 납부 특례

상시 고용인원이 20인 이하인 소규모 사업장은 **반기별 납부 (Semi-annual Payment)**를 신청할 수 있다.

| 구분 | 해당 기간 | 납부 기한 |
|------|-----------|-----------|
| 상반기 | 1월~6월 | 7월 10일 |
| 하반기 | 7월~12월 | 다음 해 1월 10일 |

반기별 납부는 관할 세무서에 승인 신청을 해야 하며, 원천징수이행상황신고서는 반기에 1회 제출한다.

### 가산세

원천징수 관련 가산세는 다음과 같다.

| 유형 | 가산세 |
|------|--------|
| 원천징수 불이행 | 미징수세액 × 10% (또는 미납세액 × 3% 중 큰 금액) |
| 납부 지연 | 미납세액 × 0.022% × 경과일수 |
| 지급명세서 미제출 | 지급금액의 1% (기한 후 제출 시 0.5%) |
| 지급명세서 불분명 | 불분명 지급금액의 1% |

원천징수 불이행 가산세와 납부 지연 가산세는 중복 적용되므로, 기한 내 징수하고 기한 내 납부하는 것이 매우 중요하다.

## 연말정산 (Year-end Tax Settlement)

연말정산은 근로소득자의 1년간 총급여에 대한 정확한 세금을 계산하여, 매월 원천징수한 세액과의 차이를 정산하는 절차이다.

### 연말정산의 의미

매월 급여에서 간이세액표에 따라 원천징수한 세금은 **대략적인 추정치**이다. 연말정산은 실제 1년간의 소득과 각종 공제를 반영하여 정확한 세금을 계산하고, 이미 납부한 세금과의 차이를 정산한다.

```
원천징수 합계 > 결정세액 → 차액 환급 (많이 뗐으니 돌려줌)
원천징수 합계 < 결정세액 → 차액 추가 징수 (덜 뗐으니 더 냄)
```

### 연말정산 일정

| 시기 | 내용 |
|------|------|
| 1월 15일경 | 국세청 간소화 서비스 (Simplified Service) 오픈 |
| 1월 중 | 근로자가 소득·세액공제 자료를 회사에 제출 |
| 2월 급여 | 연말정산 결과 반영 (환급 또는 추가 징수) |
| 3월 10일 | 연말정산 분 원천징수이행상황신고서 제출·납부 |

### 연말정산의 주요 공제 항목

**소득공제 (Income Deduction)** - 과세표준을 줄여주는 공제:
| 공제 항목 | 내용 |
|-----------|------|
| 인적공제 (Personal Exemption) | 본인·배우자·부양가족 1인당 150만원 |
| 국민연금 보험료 | 근로자 부담분 전액 공제 |
| 건강보험·고용보험 | 근로자 부담분 전액 공제 |
| 주택자금공제 | 주택임차차입금, 장기주택저당차입금 이자상환 |
| 신용카드 등 소득공제 | 총급여의 25% 초과 사용액의 15~40% |

**세액공제 (Tax Credit)** - 산출세액에서 직접 차감하는 공제:
| 공제 항목 | 내용 |
|-----------|------|
| 근로소득세액공제 | 산출세액에 따라 최대 74만원 |
| 자녀세액공제 | 자녀 1인당 15만원 (3명 이상 추가 공제) |
| 연금계좌세액공제 | 납입액의 12~15% |
| 보험료세액공제 | 보장성보험 납입액의 12% |
| 의료비세액공제 | 총급여의 3% 초과분의 15% |
| 교육비세액공제 | 납입액의 15% |
| 기부금세액공제 | 기부액의 15~30% |
| 월세세액공제 | 월세액의 15~17% (무주택 세대주) |

### 연말정산 계산 구조

```
① 총급여 (Total Salary) - 비과세소득 제외
② (-) 근로소득공제 (Employment Income Deduction) → 근로소득금액
③ (-) 인적공제 + 특별소득공제 + 기타소득공제 → 과세표준
④ (×) 기본세율 (6~45%) → 산출세액
⑤ (-) 세액공제 (근로소득, 자녀, 연금, 보험료, 의료비, 교육비, 기부금 등) → 결정세액
⑥ (-) 기납부세액 (매월 원천징수한 세액) → 차감징수세액
```

차감징수세액이 음수 (-)이면 환급, 양수 (+)이면 추가 납부이다.

## 지급명세서 (Payment Statement)

지급명세서는 원천징수 의무자가 소득을 지급한 내역을 국세청에 제출하는 서류이다. 국세청이 개인별 소득을 파악하는 핵심 자료이다.

### 지급명세서의 종류와 제출 기한

| 소득 유형 | 제출 기한 |
|-----------|-----------|
| 근로소득 (연말정산) | 다음 해 3월 10일 |
| 퇴직소득 | 다음 해 3월 10일 |
| 사업소득 (인적용역) | 다음 해 3월 10일 (반기별 제출: 7/31, 다음 해 1/31) |
| 이자·배당소득 | 다음 해 2월 말일 |
| 기타소득 | 다음 해 3월 10일 |
| 일용근로소득 | 지급일이 속하는 분기 마지막 달의 다음 달 말일 |

### 지급명세서 주요 기재 사항

1. 원천징수 의무자 정보 (사업자등록번호, 상호, 대표자)
2. 소득자 정보 (성명, 주민등록번호)
3. 소득 구분 및 소득 금액
4. 원천징수 세액
5. 비과세 소득 내역
6. 각종 공제 내역 (연말정산 대상인 경우)

### 전자 제출

지급명세서는 **홈택스 (Hometax)**를 통해 전자적으로 제출하는 것이 일반적이다. 전자 제출 시 세액 공제 혜택이 있다.

- 전자 제출 세액공제: 건당 2원 (최대 해당 과세기간 한도)

미제출 또는 불분명 기재 시 지급금액의 1% 가산세가 부과되므로 정확한 작성과 기한 내 제출이 중요하다.

## 일용근로소득의 원천징수

일용근로자 (Daily Worker)는 일정한 고용주에게 3개월 미만 고용되어 근로를 제공하는 자를 말한다. 건설일용직이 대표적이다.

### 원천징수 방법

```
① 일급여 - 비과세 15만원 = 과세 대상 금액
② 과세 대상 금액 × 6% = 산출세액
③ 산출세액 - 산출세액의 55% (근로소득세액공제) = 결정세액
④ 결정세액 + 결정세액의 10% (지방소득세) = 총 원천징수액
```

**계산 예시:**
```
일급여 200,000원:
  과세 대상: 200,000 - 150,000 = 50,000원
  산출세액: 50,000 × 6% = 3,000원
  세액공제: 3,000 × 55% = 1,650원
  결정세액: 3,000 - 1,650 = 1,350원
  지방소득세: 1,350 × 10% = 135원
  총 원천징수액: 1,485원
  실수령액: 198,515원
```

일용근로소득은 분리과세 (Separate Taxation)로 과세가 종결되므로, 종합소득세 확정신고 의무가 없다.

## 비거주자에 대한 원천징수

비거주자 (Non-resident)에게 국내원천소득을 지급하는 경우에도 원천징수 의무가 있다. 비거주자에 대한 원천징수 세율은 소득 유형에 따라 다르며, **조세조약 (Tax Treaty)**이 체결된 국가의 거주자인 경우 조약에 따른 제한세율 (Limited Tax Rate)이 적용될 수 있다.

| 소득 유형 | 국내세법 세율 | 조세조약 (일반) |
|-----------|-------------|----------------|
| 이자소득 | 20% | 10~15% |
| 배당소득 | 20% | 5~15% |
| 사용료 소득 (Royalty) | 20% | 0~15% |
| 인적용역 소득 | 20% | 면제 가능 |
| 사업소득 | 2% (총수입) 또는 20% (순소득) | 고정사업장 없으면 면세 |

조세조약 적용을 위해서는 **비거주자의 거주자증명서 (Certificate of Residence)**와 **제한세율적용신청서**를 소득 지급 전까지 제출받아야 한다.

## 개발자가 알아야 할 것 (What Developers Need to Know)

### 시스템 설계 시 고려 사항

1. **소득 유형별 세율 관리**: 소득 유형 (근로, 사업, 기타, 이자, 배당, 퇴직 등)에 따라 원천징수 세율과 계산 방식이 모두 다르다. 소득 유형 코드와 세율 매핑 테이블을 설계하고, 세율 변경에 대응할 수 있는 구조가 필요하다.

2. **간이세액표 관리**: 근로소득 원천징수를 위한 간이세액표는 매년 변경될 수 있다. 국세청에서 제공하는 간이세액표를 DB 또는 외부 파일로 관리하고, 월급여액과 부양가족 수에 따른 조회 로직이 필요하다.

3. **지방소득세 연계 처리**: 원천징수 소득세의 10%에 해당하는 지방소득세를 함께 계산·징수해야 한다. 국세 (소득세)와 지방세 (지방소득세)는 납부처가 다르므로 (홈택스 vs 위택스) 별도 처리가 필요하다.

4. **신고·납부 일정 관리**: 매월 10일 (또는 반기 납부)의 납부 기한과 지급명세서 제출 기한을 관리하는 일정 시스템이 필요하다. 공휴일·주말에 따른 기한 연장 로직도 포함해야 한다.

5. **연말정산 프로세스**: 매년 1~2월에 수행하는 연말정산은 근로소득 원천징수 시스템의 핵심 기능이다. 국세청 간소화 자료 연동, 각종 공제 계산, 결정세액 산출, 차감징수세액 계산 등 복잡한 로직이 필요하다.

6. **지급명세서 자동 생성**: 소득 유형별 지급명세서를 자동 생성하고 홈택스에 전자 제출하는 기능이 필요하다. 국세청이 정한 파일 규격 (CSV, XML 등)에 맞춰야 한다.

### 데이터 모델링 포인트

```
WithholdingTax (원천징수)
├── withholding_id (원천징수 ID)
├── income_type (소득 유형: 근로/사업/기타/이자/배당/퇴직)
├── payer_id (지급자 ID, 원천징수 의무자)
├── payee_id (소득자 ID, 납세의무자)
├── payment_date (지급일)
├── gross_amount (총지급액)
├── non_taxable_amount (비과세액)
├── taxable_amount (과세 대상 금액)
├── income_tax (원천징수 소득세)
├── local_income_tax (지방소득세)
├── net_payment (실수령액)
├── filing_month (신고 귀속월)
└── filing_status (신고 상태: 미신고/신고/수정신고)

WithholdingReturn (원천징수이행상황신고)
├── return_id (신고서 ID)
├── filing_period (신고 귀속기간: 월/반기)
├── filing_date (신고일)
├── due_date (납부기한)
├── total_income_tax (소득세 합계)
├── total_local_tax (지방소득세 합계)
├── refund_amount (환급세액)
├── tax_payable (납부할 세액)
└── payment_status (납부 상태)

PaymentStatement (지급명세서)
├── statement_id (지급명세서 ID)
├── income_type (소득 유형)
├── tax_year (귀속연도)
├── payee_info (소득자 정보)
├── total_payment (총 지급액)
├── total_tax_withheld (총 원천징수세액)
├── submission_date (제출일)
├── submission_method (제출방법: 전자/서면)
└── due_date (제출기한)
```

## 용어 사전 (Glossary)

| 한글 | 영문 | 설명 |
|------|------|------|
| 원천징수 | Withholding Tax | 소득 지급 시 세금을 미리 징수하여 납부하는 제도 |
| 원천징수 의무자 | Withholding Agent | 소득을 지급하고 세금을 징수·납부할 의무가 있는 자 |
| 간이세액표 | Simplified Tax Table | 근로소득 원천징수 시 적용하는 세액 산정표 |
| 근로소득 | Employment Income | 근로의 제공으로 받는 급여 등 모든 대가 |
| 사업소득 | Business Income | 독립적 사업 영위로 얻는 소득 |
| 기타소득 | Other Income | 일시적·비반복적으로 발생하는 소득 |
| 이자소득 | Interest Income | 금전 사용 대가로 받는 소득 |
| 배당소득 | Dividend Income | 주식 배당 등으로 받는 소득 |
| 퇴직소득 | Retirement Income | 퇴직 시 받는 퇴직급여 등 |
| 연말정산 | Year-end Tax Settlement | 근로소득의 연간 세금을 정산하는 절차 |
| 지급명세서 | Payment Statement | 소득 지급 내역을 국세청에 보고하는 서류 |
| 원천징수이행상황신고서 | Monthly Withholding Tax Return | 매월 원천징수 내역을 신고하는 서류 |
| 기납부세액 | Prepaid Tax | 원천징수로 이미 납부한 세액 |
| 분리과세 | Separate Taxation | 다른 소득과 합산하지 않고 별도로 과세 종결 |
| 금융소득 종합과세 | Comprehensive Taxation of Financial Income | 이자·배당소득 합계 2,000만원 초과 시 종합과세 |
| 비거주자 | Non-resident | 국내에 주소·거소를 두지 않은 개인 |
| 조세조약 | Tax Treaty | 이중과세 방지를 위한 국가 간 협정 |
