# 손익계산서 (Income Statement)

> 📚 **선수 지식**: [계정과목 이해하기](./03-chart-of-accounts.md), [재무상태표](./05-balance-sheet.md)

## 손익계산서란 무엇인가

손익계산서 (Income Statement)는 **일정 기간** 동안 기업이 얼마를 벌고 (수익), 얼마를 썼는지 (비용)를 보여주는 재무제표이다. 재무상태표 (Balance Sheet)가 특정 시점의 스냅샷이라면, 손익계산서는 일정 기간 동안의 동영상과 같다.

"2025년 1월 1일부터 2025년 12월 31일까지"처럼 **기간**이 명시되는 것이 재무상태표와의 핵심 차이이다. 포괄손익계산서 (Statement of Comprehensive Income)라는 이름으로도 불리며, K-IFRS 적용 기업은 포괄손익계산서를 작성한다.

### 손익계산서의 목적

1. **경영 성과 측정**: 기업이 일정 기간 동안 얼마나 효율적으로 이익을 창출했는지 평가한다
2. **수익성 분석**: 매출총이익률, 영업이익률, 순이익률 등 수익성 지표를 도출할 수 있다
3. **비용 구조 파악**: 어디에 돈을 많이 쓰고 있는지 파악하여 비용 절감 기회를 찾는다
4. **과세소득 산정**: 법인세 또는 소득세 계산의 기초가 된다
5. **미래 예측**: 과거 손익 추세를 분석하여 미래 실적을 예측하는 데 활용한다

---

## 손익계산서의 구조: 이익의 단계별 흐름

손익계산서는 매출에서 시작하여 단계적으로 비용을 차감하며 최종 순이익에 도달하는 구조이다. 이 흐름을 이해하는 것이 핵심이다.

```
매출액 (Sales/Revenue)
  - 매출원가 (Cost of Goods Sold; COGS)
────────────────────────────────
= 매출총이익 (Gross Profit)
  - 판매비와관리비 (Selling, General & Administrative; SG&A)
────────────────────────────────
= 영업이익 (Operating Income)
  + 영업외수익 (Non-operating Income)
  - 영업외비용 (Non-operating Expenses)
────────────────────────────────
= 법인세비용차감전순이익 (Income Before Tax)
  - 법인세비용 (Income Tax Expense)
────────────────────────────────
= 당기순이익 (Net Income)
```

각 단계의 이익이 무엇을 의미하는지 살펴보자.

## 매출액 (Sales / Revenue)

매출액은 기업의 주요 영업 활동에서 발생한 수익의 총액이다. 상품 판매 기업이라면 상품 매출, 서비스 기업이라면 용역 매출이 여기에 해당한다.

### 매출액의 구성

- **상품매출 (Sales of Goods)**: 완제품이나 상품을 판매하여 얻은 수익
- **제품매출 (Sales of Products)**: 자체 제조한 제품을 판매하여 얻은 수익
- **용역매출 (Service Revenue)**: 서비스를 제공하여 얻은 수익

### 수익 인식 (Revenue Recognition) 원칙

수익은 현금을 받았을 때가 아니라, **수익이 실현되었거나 실현가능하고, 수익 과정이 완료되었을 때** 인식한다. 이를 발생주의 (Accrual Basis) 원칙이라 한다.

K-IFRS 제1115호 (고객과의 계약에서 생기는 수익)에 따른 5단계 수익 인식 모형:

1. **계약 식별** (Identify the contract): 고객과의 계약을 식별한다
2. **수행의무 식별** (Identify performance obligations): 계약 내 별도의 수행의무를 식별한다
3. **거래가격 산정** (Determine transaction price): 계약의 거래가격을 산정한다
4. **거래가격 배분** (Allocate transaction price): 거래가격을 각 수행의무에 배분한다
5. **수익 인식** (Recognize revenue): 수행의무를 이행할 때 수익을 인식한다

### 매출 관련 차감 항목

- **매출에누리 (Sales Allowances)**: 품질 불량 등으로 가격을 깎아주는 것
- **매출할인 (Sales Discounts)**: 조기 결제 할인 (예: 2/10, n/30 - 10일 이내 결제 시 2% 할인)
- **매출환입 (Sales Returns)**: 반품으로 돌아온 상품의 금액

**순매출액 (Net Sales)** = 총매출액 - 매출에누리 - 매출할인 - 매출환입

## 매출원가 (Cost of Goods Sold; COGS)

매출원가는 판매된 상품이나 제품을 만드는 데 직접 들어간 비용이다. 매출과 직접적으로 대응되는 비용만 포함한다.

### 상품매매업의 매출원가 계산

```
기초상품재고액 (Beginning Inventory)
  + 당기상품매입액 (Purchases)
────────────────────────────────
= 판매가능상품원가 (Goods Available for Sale)
  - 기말상품재고액 (Ending Inventory)
────────────────────────────────
= 매출원가 (COGS)
```

**예시**: 기초재고 1,000만 원, 당기매입 5,000만 원, 기말재고 1,500만 원인 경우
- 매출원가 = 1,000 + 5,000 - 1,500 = **4,500만 원**

### 제조업의 매출원가 계산

제조업은 원재료비 (Raw Materials), 노무비 (Direct Labor), 제조경비 (Manufacturing Overhead)로 구성되는 제조원가가 매출원가의 기초가 된다.

```
기초제품재고액
  + 당기제품제조원가
────────────────────────────────
= 판매가능제품원가
  - 기말제품재고액
────────────────────────────────
= 매출원가
```

---

## 매출총이익 (Gross Profit)

```
매출총이익 = 매출액 - 매출원가
```

매출총이익은 기업의 핵심 영업 활동의 기본적인 수익성을 나타낸다. **매출총이익률 (Gross Profit Margin)**은 매출총이익을 매출액으로 나눈 비율이다.

```
매출총이익률 = 매출총이익 / 매출액 × 100
```

업종별로 매출총이익률이 크게 다르다:
- **소매업**: 20~40%
- **제조업**: 25~50%
- **소프트웨어/IT**: 60~90%
- **서비스업**: 50~70%

---

## 판매비와관리비 (SG&A; Selling, General & Administrative Expenses)

판매비와관리비 (판관비)는 상품을 판매하고 기업을 관리하는 데 드는 비용이다. 매출원가에 포함되지 않는 영업 관련 비용이 여기에 해당한다.

### 주요 판관비 항목

| 계정과목 | 영문 | 설명 |
|---------|------|------|
| 급여 | Salaries | 임직원 급여 (생산직 제외) |
| 퇴직급여 | Retirement Benefits | 퇴직금 충당액 |
| 복리후생비 | Employee Benefits | 4대 보험 회사 부담분, 식대, 경조사비 등 |
| 여비교통비 | Travel Expenses | 출장비, 교통비 |
| 접대비 | Entertainment Expenses | 거래처 접대 비용 (세법상 한도 있음) |
| 통신비 | Communication Expenses | 전화, 인터넷, 우편 비용 |
| 수도광열비 | Utilities | 전기, 수도, 가스 비용 |
| 세금과공과 | Taxes and Dues | 재산세, 자동차세, 각종 공과금 |
| 감가상각비 | Depreciation | 유형자산의 감가상각비 (생산 관련 제외) |
| 임차료 | Rent | 사무실, 매장 임대료 |
| 보험료 | Insurance | 화재보험, 배상책임보험 등 |
| 차량유지비 | Vehicle Maintenance | 유류비, 수리비, 자동차보험 |
| 운반비 | Delivery Expenses | 상품 배송비 |
| 교육훈련비 | Training Expenses | 직원 교육 비용 |
| 도서인쇄비 | Printing and Stationery | 도서 구입비, 인쇄비 |
| 소모품비 | Supplies | 사무용품 등 소모품 |
| 지급수수료 | Commission Expenses | 법률자문료, 회계감사 수수료 등 |
| 광고선전비 | Advertising | 광고비, 홍보비 |
| 대손상각비 | Bad Debt Expense | 매출채권 회수 불능 추정 비용 |
| 무형자산상각비 | Amortization | 무형자산의 상각비 |

### 비용 인식 (Expense Recognition) 원칙

비용은 관련 수익이 인식되는 기간에 함께 인식한다. 이를 **수익·비용 대응의 원칙 (Matching Principle)**이라 한다.

- **직접 대응**: 매출원가처럼 특정 수익과 직접 연결되는 비용
- **기간 대응**: 급여, 임차료처럼 특정 기간에 걸쳐 발생하는 비용
- **즉시 인식**: 기부금처럼 수익과 직접 대응시킬 수 없는 비용

## 영업이익 (Operating Income)

```
영업이익 = 매출총이익 - 판매비와관리비
```

영업이익은 기업의 **본업에서 벌어들인 이익**이다. 기업의 핵심 경쟁력을 가장 잘 보여주는 지표로, 투자자와 분석가가 가장 중시하는 이익 단계이다.

**영업이익률 (Operating Profit Margin)**:
```
영업이익률 = 영업이익 / 매출액 × 100
```

## 영업외수익과 영업외비용

주요 영업 활동 이외에서 발생하는 수익과 비용이다.

### 영업외수익 (Non-operating Income)

| 계정과목 | 영문 | 설명 |
|---------|------|------|
| 이자수익 | Interest Income | 예금, 대여금 등에서 발생하는 이자 |
| 배당금수익 | Dividend Income | 보유 주식에서 받는 배당금 |
| 임대료수익 | Rental Income | 부동산 임대 수익 |
| 유형자산처분이익 | Gain on Disposal of PP&E | 유형자산 처분 시 장부가액 초과 금액 |
| 외환차익 | Foreign Exchange Gain | 환율 변동으로 인한 이익 |
| 외화환산이익 | Foreign Currency Translation Gain | 외화 자산·부채 환산 시 발생하는 이익 |
| 잡이익 | Miscellaneous Income | 기타 분류하기 어려운 수익 |

### 영업외비용 (Non-operating Expenses)

| 계정과목 | 영문 | 설명 |
|---------|------|------|
| 이자비용 | Interest Expense | 차입금에 대한 이자 비용 |
| 유형자산처분손실 | Loss on Disposal of PP&E | 유형자산 처분 시 장부가액 미달 금액 |
| 외환차손 | Foreign Exchange Loss | 환율 변동으로 인한 손실 |
| 외화환산손실 | Foreign Currency Translation Loss | 외화 자산·부채 환산 시 발생하는 손실 |
| 기부금 | Donations | 사회공헌 활동 등 기부 비용 |
| 재해손실 | Casualty Loss | 자연재해 등으로 인한 손실 |
| 잡손실 | Miscellaneous Loss | 기타 분류하기 어려운 비용 |

## 법인세비용과 당기순이익

### 법인세비용차감전순이익 (Income Before Tax)

```
법인세비용차감전순이익 = 영업이익 + 영업외수익 - 영업외비용
```

### 법인세비용 (Income Tax Expense)

법인세는 기업의 소득에 대해 부과되는 세금이다. 한국의 법인세율 (2025년 기준):

| 과세표준 구간 | 세율 |
|-------------|------|
| 2억 원 이하 | 9% |
| 2억 원 초과 ~ 200억 원 이하 | 19% |
| 200억 원 초과 ~ 3,000억 원 이하 | 21% |
| 3,000억 원 초과 | 24% |

주의: 회계상 이익과 세법상 과세소득은 다를 수 있다. 이 차이를 **세무조정 (Tax Adjustment)**이라 하며, 이로 인해 이연법인세 (Deferred Tax) 개념이 발생한다.

### 당기순이익 (Net Income)

```
당기순이익 = 법인세비용차감전순이익 - 법인세비용
```

당기순이익은 모든 수익과 비용을 차감한 후의 **최종 이익**이다. 이 금액이 재무상태표의 이익잉여금 (Retained Earnings)에 누적된다.

Ⅰ. 매출액 (Revenue)                        500,000
    상품매출                    450,000
    용역매출                     50,000

Ⅱ. 매출원가 (COGS)                         300,000
    기초상품재고액               30,000
    당기상품매입액              305,000
    기말상품재고액              (35,000)

------------------------------------------------------------
Ⅲ. 매출총이익 (Gross Profit)               200,000

Ⅳ. 판매비와관리비 (SG&A)                   140,000
    급여                         60,000
    퇴직급여                      6,000
    복리후생비                   10,000
    임차료                       18,000
    감가상각비                   12,000
    접대비                        5,000
    광고선전비                    8,000
    세금과공과                    4,000
    지급수수료                    7,000
    소모품비                      3,000
    대손상각비                    2,500
    기타                          4,500

------------------------------------------------------------
Ⅴ. 영업이익 (Operating Income)              60,000

Ⅵ. 영업외수익                               8,000
    이자수익                      5,000
    임대료수익                    2,000
    잡이익                        1,000

Ⅶ. 영업외비용                              12,000
    이자비용                      9,000
    유형자산처분손실               2,000

------------------------------------------------------------
Ⅷ. 법인세비용차감전순이익                   56,000

| 지표 | 계산 | 결과 |
|------|------|------|
| 매출총이익률 (Gross Margin) | 200,000 / 500,000 × 100 | 40.0% |
| 영업이익률 (Operating Margin) | 60,000 / 500,000 × 100 | 12.0% |
| 순이익률 (Net Profit Margin) | 45,360 / 500,000 × 100 | 9.1% |

## 손익계산서 읽을 때 주의할 점

### 매출액 성장률 확인

전년 대비 매출이 얼마나 성장했는지가 기업의 성장세를 보여준다. 매출액이 줄어들고 있다면 시장 경쟁력이 약화되고 있다는 신호일 수 있다.

### 이익률 추이 분석

단년도 이익률보다 **3~5년간의 추이**가 더 중요하다. 매출은 성장하는데 이익률이 하락하고 있다면 비용 구조에 문제가 있을 수 있다.

### 영업이익과 당기순이익의 괴리

영업이익은 좋은데 당기순이익이 나쁘다면 영업외비용 (특히 이자비용)이 과다한 것이다. 반대로 영업이익은 나쁜데 당기순이익이 좋다면 일회성 영업외수익 (자산 매각 등)으로 분식한 것일 수 있다.

### 감가상각비의 현금흐름 영향

감가상각비 (Depreciation)는 실제 현금이 나가지 않는 비용이다. 따라서 손익계산서상 이익이 적더라도 실제 현금 흐름은 양호할 수 있다. EBITDA (Earnings Before Interest, Taxes, Depreciation and Amortization)를 함께 보는 이유가 이것이다.

## 개발자가 알아야 할 것 (What Developers Need to Know)

### 시스템 설계에 미치는 영향

- **기간별 집계 로직**: 손익계산서는 기간 기반 보고서이므로, 회계기간 (Fiscal Period) 설정과 기간별 거래 집계가 정확해야 한다. 마감 전/후 구분 로직이 필수이다.
- **매출원가 자동 계산**: 재고 시스템과 연동하여 기초재고, 매입, 기말재고를 기반으로 매출원가를 자동 계산하는 로직이 필요하다.
- **다단계 이익 계산**: 매출총이익 → 영업이익 → 당기순이익의 단계별 계산이 정확해야 하며, 각 단계별 이익률을 실시간 대시보드에 표시하는 것이 일반적이다.
- **수익 인식 시점 처리**: SaaS 등 구독형 서비스의 경우 선수수익 (Unearned Revenue)을 월별로 분할 인식하는 로직이 핵심이다.

### 데이터 모델링 포인트

- **계정과목별 집계**: 손익계산서 항목 (매출, 매출원가, 판관비 등)을 계정과목 분류 코드로 자동 집계할 수 있어야 한다
- **비교 기간 조회**: 전기 대비 당기 비교가 가능해야 하므로, 복수 회계기간의 데이터를 병렬 조회하는 기능이 필요하다
- **세부 항목 드릴다운**: 판관비 총액에서 개별 계정과목, 나아가 개별 거래까지 추적할 수 있는 구조가 필요하다
- **세무조정 연동**: 회계상 이익과 세무상 과세소득의 차이를 관리하는 별도 테이블이 필요하다

### ERP 및 회계 프로그램 연동 시 참고 사항

- **손익 자동 집계**: 분개 데이터에서 수익/비용 계정을 기간별로 집계하여 손익계산서를 동적 생성한다
- **부문별 손익**: 부서, 프로젝트, 제품 라인별로 손익을 구분 관리하는 것이 일반적이다. 계정과목 외에 부문 코드 (Segment Code)가 필요하다
- **예산 대비 실적**: 예산 (Budget) 데이터와 실적 (Actual) 데이터를 비교하는 기능이 경영진에게 중요하다
- **국세청 전자신고**: 법인세 신고 시 손익계산서 데이터가 전자신고 시스템 (Home Tax)에 자동 연동되어야 한다

## 용어 사전 (Glossary)

| 한글 | 영문 | 설명 |
|------|------|------|
| 손익계산서 | Income Statement (P&L) | 일정 기간의 수익과 비용을 보여주는 재무제표 |
| 매출액 | Sales / Revenue | 주요 영업 활동에서 발생한 수익의 총액 |
| 매출원가 | Cost of Goods Sold (COGS) | 판매된 상품·제품의 직접 원가 |
| 매출총이익 | Gross Profit | 매출액에서 매출원가를 차감한 이익 |
| 판매비와관리비 | SG&A Expenses | 판매·관리 활동에 소요되는 비용 총칭 |
| 영업이익 | Operating Income | 매출총이익에서 판관비를 차감한 본업의 이익 |
| 영업외수익 | Non-operating Income | 본업 외에서 발생한 수익 (이자수익, 임대수익 등) |
| 영업외비용 | Non-operating Expenses | 본업 외에서 발생한 비용 (이자비용, 처분손실 등) |
| 당기순이익 | Net Income | 모든 수익에서 모든 비용을 차감한 최종 이익 |
| 수익 인식 | Revenue Recognition | 수익을 재무제표에 기록하는 시점과 금액의 결정 원칙 |
| 발생주의 | Accrual Basis | 현금 수수와 관계없이 경제적 사건 발생 시 인식하는 원칙 |
| 대응 원칙 | Matching Principle | 수익과 관련 비용을 같은 기간에 인식하는 원칙 |
| 매출총이익률 | Gross Profit Margin | 매출총이익 / 매출액 × 100 (%) |
| 영업이익률 | Operating Profit Margin | 영업이익 / 매출액 × 100 (%) |
| 세무조정 | Tax Adjustment | 회계 이익과 과세소득의 차이를 조정하는 절차 |
