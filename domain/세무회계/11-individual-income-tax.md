## 1. 개인사업자의 세무 의무 전체 개요

개인사업자(Sole Proprietor)는 법인을 설립하지 않고 개인 명의로 사업을 영위하는 사업자를 말한다. 한국에서 개인사업자가 부담하는 주요 세무 의무는 다음과 같다.

```
┌─────────────────────────────────────────────────────────────────┐
│                  개인사업자 연간 세무 일정                         │
├──────────┬──────────────────────────────────────────────────────┤
│  1월     │ 부가가치세 확정신고 (2기, 전년 7~12월분)               │
│  3월     │ 원천세 연말정산 (직원이 있는 경우)                      │
│  4월     │ 부가가치세 예정신고 (1기, 1~3월분)                     │
│  5월     │ ★ 종합소득세 확정신고 (전년도 소득)                     │
│  7월     │ 부가가치세 확정신고 (1기, 1~6월분)                     │
│  10월    │ 부가가치세 예정신고 (2기, 7~9월분)                     │
│  11월    │ 종합소득세 중간예납 (해당되는 경우)                      │
│  매월    │ 원천세 신고·납부 (직원이 있는 경우)                      │
└──────────┴──────────────────────────────────────────────────────┘
```

### 개인사업자의 주요 세무 의무

| 의무 | 내용 | 기한 |
|------|------|------|
| 사업자등록 (Business Registration) | 사업 개시 전 또는 개시일로부터 20일 이내 | 사업 개시 시 |
| 부가가치세 신고 (VAT Filing) | 매출·매입 세금계산서 기반 신고 | 분기별 |
| 종합소득세 신고 (Income Tax Filing) | 1년간 소득을 합산하여 신고 | 매년 5월 |
| 원천징수 (Withholding Tax) | 직원 급여, 프리랜서 대가에서 세금 원천징수 | 매월 10일 |
| 장부 기장 (Bookkeeping) | 사업 거래를 장부에 기록 | 상시 |
| 세금계산서 발행 (Tax Invoice Issuance) | 재화·용역 공급 시 발행 | 거래 시 |

개인사업자에게 가장 중요한 세금 신고는 **5월 종합소득세 확정신고**다. 이 신고에서 전년도 1월 1일부터 12월 31일까지의 모든 소득을 합산하여 최종 세금을 계산한다.

## 2. 종합소득세의 개념

종합소득세(Comprehensive Income Tax)는 개인이 1년간 벌어들인 모든 종류의 소득을 합산(종합)하여 과세하는 세금이다. "종합"이라는 이름이 붙은 이유는 하나의 소득만이 아니라 여러 소득을 합쳐서 세금을 계산하기 때문이다.

### 종합소득세의 핵심 원리

- **인적 과세 (Personal Taxation)**: 법인이 아닌 개인(자연인)에게 부과한다.
- **종합 과세 (Aggregate Taxation)**: 여러 종류의 소득을 하나로 합산하여 과세한다.
- **누진 과세 (Progressive Taxation)**: 소득이 높을수록 높은 세율을 적용한다.
- **신고납세 (Self-Assessment)**: 납세자가 스스로 소득과 세금을 계산하여 신고한다.

### 종합소득세 계산의 전체 흐름

```
 총수입금액 (Gross Revenue)
      │
      │  (-) 필요경비 (Necessary Expenses)
      ▼
 소득금액 (Income Amount)   ← 각 소득별로 계산
      │
      │  합산 (6가지 소득)
      ▼
 종합소득금액 (Comprehensive Income)
      │
      │  (-) 소득공제 (Income Deductions)
      ▼
 과세표준 (Tax Base)
      │
      │  (×) 세율 (Tax Rate, 6%~45%)
      ▼
 산출세액 (Calculated Tax)
      │
      │  (-) 세액공제 (Tax Credits)
      │  (-) 세액감면 (Tax Reduction)
      ▼
 결정세액 (Determined Tax)
      │
      │  (-) 기납부세액 (Prepaid Tax)
      │      ├ 중간예납세액
      │      ├ 원천징수세액
      │      └ 수시부과세액
      ▼
 납부할 세액 (Tax Payable) or 환급세액 (Tax Refund)
```

## 3. 종합소득의 구성

종합소득(Comprehensive Income)은 다음 **6가지 소득**을 합산한 것이다.

| 소득 종류 | 영문 | 설명 | 예시 |
|-----------|------|------|------|
| 사업소득 (Business Income) | Business Income | 사업 활동에서 발생하는 소득 | 매출 - 비용 |
| 근로소득 (Employment Income) | Employment Income | 고용 관계에서 받는 급여 | 월급, 상여금 |
| 이자소득 (Interest Income) | Interest Income | 금융기관 예적금 등의 이자 | 은행 이자 |
| 배당소득 (Dividend Income) | Dividend Income | 주식 배당금 | 주식 배당 |
| 연금소득 (Pension Income) | Pension Income | 공적·사적 연금 수령액 | 국민연금, 퇴직연금 |
| 기타소득 (Other Income) | Other Income | 위에 해당하지 않는 일시적 소득 | 강연료, 원고료, 복권 당첨금 |

### 분리과세 vs 종합과세

모든 소득이 항상 종합과세 되는 것은 아니다. 일정 조건에서는 분리과세(Separate Taxation)를 선택하거나 강제된다.

```
┌──────────────────────────────────────────────────────────────┐
│                    소득 과세 방식 분류                         │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  이자·배당소득                                                │
│    ├─ 연간 2,000만 원 이하 → 분리과세 (15.4%)                 │
│    └─ 연간 2,000만 원 초과 → 종합과세 (금융소득종합과세)        │
│                                                              │
│  기타소득                                                    │
│    ├─ 연간 300만 원 이하 → 분리과세 선택 가능                  │
│    └─ 연간 300만 원 초과 → 종합과세                            │
│                                                              │
│  사업소득, 근로소득 → 항상 종합과세                             │
│                                                              │
│  연금소득                                                    │
│    ├─ 연간 1,500만 원 이하 → 분리과세 선택 가능                │
│    └─ 연간 1,500만 원 초과 → 종합과세                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

개인사업자의 경우 **사업소득**이 핵심이며, 이는 항상 종합과세 대상이다. 다른 소득이 함께 있다면 합산되어 세율 구간이 올라갈 수 있다.

## 4. 사업소득 계산 구조

사업소득(Business Income)은 개인사업자의 세무에서 가장 중요한 소득 항목이다.

### 기본 계산식

```
사업소득금액 = 총수입금액 (Gross Revenue) - 필요경비 (Necessary Expenses)
```

### 총수입금액 (Gross Revenue)

총수입금액은 사업 활동으로 발생한 모든 수입을 말한다.

- 매출액 (Sales Revenue)
- 부산물 매출 (By-product Sales)
- 자가소비액 (Self-consumption)
- 사업과 관련된 보험차익, 보상금 등

**주의**: 부가가치세 매출세액은 총수입금액에 포함하지 않는다. 부가가치세는 사업자가 대신 걷어서 납부하는 세금이므로 수입이 아니다.

### 필요경비 (Necessary Expenses) 인정 범위

필요경비란 사업 수입을 얻기 위해 직접 또는 간접적으로 지출한 비용 중 세법상 인정되는 비용이다.

#### 주요 인정 항목

| 구분 | 항목 | 비고 |
|------|------|------|
| 인건비 (Labor Cost) | 직원 급여, 일용직 급여, 퇴직급여 | 가족 인건비는 요건 충족 시 |
| 임차료 (Rent) | 사무실·점포 임대료 | 사업용 공간에 한함 |
| 매입비용 (Purchase Cost) | 원재료비, 상품 매입액 | 적격증빙 필요 |
| 감가상각비 (Depreciation) | 사업용 고정자산 감가상각 | 세법상 한도 있음 |
| 수선비 (Repair Cost) | 사업용 자산 수선 유지비 | 자본적 지출 제외 |
| 통신비 (Communication) | 사업용 전화, 인터넷 요금 | 사업용 비율만큼 |
| 차량유지비 (Vehicle Expense) | 사업용 차량 관련 비용 | 업무용승용차 한도 적용 |
| 세금과공과 (Taxes & Dues) | 사업 관련 세금, 공과금 | 소득세, 주민세 제외 |
| 접대비 (Entertainment) | 사업 관련 접대비 | 한도액 있음 |
| 광고선전비 (Advertising) | 사업 관련 홍보·광고비 | |
| 기부금 (Donation) | 법정·지정 기부금 | 한도액 있음 |
| 대손금 (Bad Debt) | 회수 불능 채권 | 요건 충족 시 |

#### 필요경비로 인정되지 않는 항목 (Non-deductible Expenses)

- 사업자 본인의 급여 (Owner's Salary) — 개인사업자는 자신에게 급여를 지급할 수 없음
- 소득세·주민세 (Income Tax, Resident Tax)
- 벌금·과료 (Fines & Penalties)
- 사적 경비 (Personal Expenses) — 사업과 무관한 개인 지출
- 증빙 없는 지출 (Undocumented Expenses) — 적격증빙 미수취분

### 사업소득 계산 예시

```
커피숍 운영 개인사업자 (연간)
─────────────────────────────────────────
총수입금액 (Gross Revenue)
  매출액                      120,000,000원
  기타 수입                     2,000,000원
  합계                        122,000,000원

필요경비 (Necessary Expenses)
  원재료비 (매입비용)           40,000,000원
  인건비                       24,000,000원
  임차료                       18,000,000원
  감가상각비                    3,000,000원
  수도광열비                    4,000,000원
  기타 경비                     8,000,000원
  합계                         97,000,000원

사업소득금액 = 122,000,000 - 97,000,000 = 25,000,000원
```

## 5. 소득공제 항목

종합소득금액에서 소득공제(Income Deduction)를 차감하면 과세표준(Tax Base)이 된다. 소득공제는 과세표준을 낮추어 적용 세율을 내리는 효과가 있다.

### 주요 소득공제 항목

#### 인적공제 (Personal Exemption)

| 공제 종류 | 금액 | 조건 |
|-----------|------|------|
| 기본공제 (Basic Exemption) | 1인당 150만 원 | 본인, 배우자, 부양가족 |
| 경로우대 (Senior Deduction) | 1인당 100만 원 | 70세 이상 |
| 장애인공제 (Disability Deduction) | 1인당 200만 원 | 장애인 |
| 부녀자공제 (Working Woman Deduction) | 50만 원 | 종합소득 3천만 원 이하 |
| 한부모공제 (Single Parent Deduction) | 100만 원 | 배우자 없이 부양자녀 있는 경우 |

#### 그 밖의 소득공제

| 공제 항목 | 내용 |
|-----------|------|
| 국민연금보험료 공제 (NPS Premium Deduction) | 납부한 국민연금 보험료 전액 |
| 건강보험료 공제 (Health Insurance Premium) | 납부한 건강보험료 |
| 주택담보대출이자 공제 (Mortgage Interest) | 무주택 또는 1주택자, 한도 있음 |
| 개인연금저축 공제 (Personal Pension) | 납입액의 40%, 연 72만 원 한도 |
| 소기업·소상공인 공제 (Small Business Deduction) | 노란우산 공제부금, 연 500만 원 한도 |

> **참고**: 개인사업자는 근로자와 달리 신용카드 소득공제, 주택청약저축 소득공제 등 근로소득자 전용 공제를 적용받을 수 없다.

## 6. 과세표준과 세율

과세표준(Tax Base)이 결정되면 해당 구간에 맞는 세율(Tax Rate)을 적용하여 산출세액(Calculated Tax)을 구한다.

### 종합소득세 누진세율표 (Progressive Tax Rate Table)

| 과세표준 (Tax Base) | 세율 (Rate) | 누진공제 (Progressive Deduction) |
|---------------------|-------------|-------------------------------|
| 1,400만 원 이하 | 6% | — |
| 1,400만 원 초과 ~ 5,000만 원 이하 | 15% | 126만 원 |
| 5,000만 원 초과 ~ 8,800만 원 이하 | 24% | 576만 원 |
| 8,800만 원 초과 ~ 1.5억 원 이하 | 35% | 1,544만 원 |
| 1.5억 원 초과 ~ 3억 원 이하 | 38% | 1,994만 원 |
| 3억 원 초과 ~ 5억 원 이하 | 40% | 2,594만 원 |
| 5억 원 초과 ~ 10억 원 이하 | 42% | 3,594만 원 |
| 10억 원 초과 | 45% | 6,594만 원 |

### 누진세율 계산 방식

누진세율(Progressive Tax Rate)은 소득 전체에 하나의 세율을 적용하는 것이 아니라, 각 구간별로 해당 세율을 적용한다. 실무에서는 **누진공제액**을 이용하면 간편하게 계산할 수 있다.

```
산출세액 = 과세표준 × 해당 세율 - 누진공제액
```

### 계산 예시

```
과세표준: 50,000,000원 (5천만 원)

방법 1: 구간별 계산
  1,400만 원 × 6%  =    840,000원
  3,600만 원 × 15% =  5,400,000원
  합계              =  6,240,000원

방법 2: 누진공제 활용
  5,000만 원 × 15% - 126만 원
  = 750만 원 - 126만 원
  = 624만 원 (= 6,240,000원)

※ 지방소득세(Local Income Tax) 10%가 별도로 부과됨
   → 6,240,000 × 10% = 624,000원
   → 실질 총 세부담: 6,864,000원
```

> **참고**: 지방소득세(Local Income Tax)는 종합소득세의 10%로, 별도 신고·납부해야 한다. 따라서 실질 세율은 표면 세율의 1.1배다.

## 7. 세액공제와 세액감면

산출세액에서 세액공제(Tax Credit)와 세액감면(Tax Reduction)을 차감하면 결정세액(Determined Tax)이 된다.

### 주요 세액공제

| 세액공제 항목 | 내용 |
|---------------|------|
| 자녀세액공제 (Child Tax Credit) | 자녀 수에 따라 연 15~30만 원 |
| 연금계좌세액공제 (Pension Account Credit) | 납입액의 12%~15%, 연 700만 원 한도 |
| 특별세액공제 — 보장성보험료 (Insurance) | 납입액의 12%, 연 100만 원 한도 |
| 특별세액공제 — 의료비 (Medical Expense) | 총급여 3% 초과분의 15% |
| 특별세액공제 — 교육비 (Education Expense) | 납입액의 15%, 한도 있음 |
| 특별세액공제 — 기부금 (Donation) | 기부금의 15%~30% |
| 외국납부세액공제 (Foreign Tax Credit) | 외국에서 납부한 세금 공제 |
| 전자신고세액공제 (E-filing Credit) | 전자신고 시 2만 원 공제 |
| 성실신고확인비용 세액공제 | 성실신고확인 비용의 60%, 120만 원 한도 |

### 세액감면 (Tax Reduction)

세액감면은 특정 조건을 충족하는 사업자에게 산출세액의 일정 비율을 감면해 주는 제도다.

- **중소기업 특별세액감면**: 업종별로 산출세액의 5%~30% 감면
- **창업중소기업 세액감면**: 창업 후 5년간 소득세의 50%~100% 감면 (수도권 과밀억제권역 외 등 조건)

```
산출세액                    6,240,000원
  (-) 자녀세액공제              150,000원
  (-) 연금계좌세액공제           540,000원
  (-) 전자신고세액공제            20,000원
─────────────────────────────────────
결정세액                    5,530,000원
  (-) 중간예납세액            2,000,000원
  (-) 원천징수세액              500,000원
─────────────────────────────────────
납부할 세액                 3,030,000원
```

## 8. 종합소득세 신고 구조

### 신고 기간과 납부

- **확정신고 기간**: 매년 5월 1일 ~ 5월 31일 (전년도 소득에 대해)
- **성실신고확인 대상자**: 6월 30일까지 연장
- **납부 방법**: 일시납부 또는 분납 가능
  - 납부세액 1,000만 원 초과 시: 2개월 이내 분납 가능
  - 납부세액 2,000만 원 초과 시: 초과분은 2개월 이내 분납

### 신고 유형 (Filing Type)

국세청은 납세자의 업종, 수입 규모, 기장 의무 등에 따라 신고 유형을 안내한다.

| 신고 유형 | 대상 | 기장 방식 |
|-----------|------|-----------|
| S유형 | 성실신고확인 대상 | 복식부기, 외부 확인 필수 |
| A유형 | 외부조정 대상 | 복식부기 의무 |
| B유형 | 자기조정 대상 | 복식부기 의무 |
| C유형 | 복식부기 의무자 중 자기조정 | 복식부기 |
| D유형 | 간편장부 대상 | 간편장부 허용 |
| E유형 | 단순경비율 대상 | 추계 가능 |
| F유형 | 기준경비율 대상 | 추계 가능 |
| G유형 | 단순경비율 소규모 | 모두채움 신고 |

### 중간예납 (Interim Payment)

중간예납은 전년도 종합소득세의 절반을 해당 연도 11월에 미리 납부하는 제도다.

- **납부 시기**: 11월 1일 ~ 11월 30일
- **납부 금액**: 전년도 종합소득세의 1/2
- **면제 기준**: 중간예납세액이 50만 원 미만이면 납부 면제
- 확정신고 시 기납부세액으로 차감됨

## 9. 성실신고확인제도

성실신고확인제도(Faithful Tax Return Confirmation System)는 일정 규모 이상의 개인사업자에 대해 세무사 등이 신고 내용의 정확성을 확인하도록 하는 제도다.

### 대상 기준 (업종별 수입금액)

| 업종 | 수입금액 기준 |
|------|--------------|
| 농업·도소매업·부동산매매업 등 | 15억 원 이상 |
| 제조업·음식숙박업·건설업 등 | 7.5억 원 이상 |
| 서비스업·부동산임대업 등 | 5억 원 이상 |

### 성실신고확인 절차

1. 사업자가 장부와 증빙서류를 세무대리인에게 제출
2. 세무대리인(세무사, 공인회계사)이 수입금액과 필요경비의 적정성 확인
3. **성실신고확인서** 첨부하여 신고
4. 신고 기한이 6월 30일까지 연장됨

### 혜택과 페널티

- **혜택**: 의료비·교육비 세액공제 적용, 성실신고확인 비용 세액공제 (60%, 120만 원 한도)
- **페널티**: 미이행 시 가산세 5% 부과, 세무조사 대상 선정 우선

## 10. 추계신고 vs 장부신고

개인사업자의 소득 계산 방법은 크게 **장부신고(Book-based Filing)**와 **추계신고(Estimation-based Filing)** 두 가지로 나뉜다.

### 장부신고 (Book-based Filing)

실제 장부를 기장하여 수입과 비용을 계산하는 방식이다.

| 구분 | 복식부기 (Double-entry) | 간편장부 (Simplified Bookkeeping) |
|------|------------------------|-----------------------------------|
| 대상 | 일정 규모 이상 사업자 | 소규모 사업자 |
| 기장 방식 | 차변·대변 분개 | 수입·지출 단순 기록 |
| 재무제표 | 재무상태표 + 손익계산서 | 간편장부 소득금액 계산서 |
| 정확성 | 높음 | 보통 |

#### 복식부기 의무자 기준

| 업종 | 수입금액 기준 |
|------|--------------|
| 농업·도소매업 등 | 3억 원 이상 |
| 제조업·음식숙박업 등 | 1.5억 원 이상 |
| 서비스업·부동산임대업 등 | 7,500만 원 이상 |

### 추계신고 (Estimation-based Filing)

장부가 없거나 불비한 경우, 정부가 정한 경비율을 적용하여 소득을 추정 계산하는 방식이다.

```
┌─────────────────────────────────────────────────────────┐
│              장부신고 vs 추계신고 비교                     │
├──────────────────┬──────────────────────────────────────┤
│                  │  장부신고           추계신고            │
├──────────────────┼──────────────────────────────────────┤
│ 소득 계산        │  실제 수입 - 실제 비용  정부 경비율 적용  │
│ 장부 필요        │  필수                   불필요          │
│ 적자(결손금)     │  이월공제 가능          불가능          │
│ 세액 감면·공제   │  대부분 적용 가능       일부 제한        │
│ 무기장가산세     │  없음                  부과될 수 있음    │
│ 정확성           │  높음                  낮음 (불리할 수 있음)│
└──────────────────┴──────────────────────────────────────┘
```

> **핵심**: 장부를 작성하면 실제 비용을 인정받아 세금이 줄어드는 경우가 많다. 특히 결손금(Loss) 이월공제는 장부신고에서만 가능하다.

## 11. 단순경비율과 기준경비율

추계신고를 할 때 적용하는 경비율에는 **단순경비율(Simple Expense Rate)**과 **기준경비율(Standard Expense Rate)** 두 가지가 있다.

### 단순경비율 (Simple Expense Rate)

소규모 사업자에게 적용되는 경비율로, 수입금액에서 경비율만큼을 필요경비로 인정한다.

```
소득금액 = 총수입금액 - (총수입금액 × 단순경비율)
         = 총수입금액 × (1 - 단순경비율)
```

#### 단순경비율 적용 대상 (직전 연도 수입금액 기준)

| 업종 | 수입금액 기준 |
|------|--------------|
| 농업·도소매업 등 | 6,000만 원 미만 |
| 제조업·음식숙박업 등 | 3,600만 원 미만 |
| 서비스업·부동산임대업 등 | 2,400만 원 미만 |

#### 계산 예시

```
음식점업 개인사업자
총수입금액: 30,000,000원
단순경비율: 89.7%

소득금액 = 30,000,000 × (1 - 0.897)
         = 30,000,000 × 0.103
         = 3,090,000원
```

### 기준경비율 (Standard Expense Rate)

단순경비율 적용 대상이 아닌 사업자 중 장부를 기장하지 않는 경우 적용된다. 주요경비(매입비용, 인건비, 임차료)는 실제 증빙으로 인정하고, 나머지 경비만 경비율을 적용한다.

```
소득금액 = 총수입금액 - 주요경비 - (총수입금액 × 기준경비율)

주요경비 = 매입비용 + 인건비 + 임차료 (증빙이 있는 것만)
```

#### 계산 예시

```
음식점업 개인사업자
총수입금액: 80,000,000원
기준경비율: 15.6%
주요경비(증빙 있음):
  매입비용: 25,000,000원
  인건비:   10,000,000원
  임차료:   12,000,000원
  합계:     47,000,000원

소득금액 = 80,000,000 - 47,000,000 - (80,000,000 × 0.156)
         = 80,000,000 - 47,000,000 - 12,480,000
         = 20,520,000원
```

### 단순경비율 vs 기준경비율 비교

| 구분 | 단순경비율 | 기준경비율 |
|------|-----------|-----------|
| 대상 | 소규모 사업자 | 단순경비율 비적용 사업자 중 무기장자 |
| 경비 인정 | 수입 × 경비율 (전체 경비) | 주요경비(증빙) + 수입 × 기준경비율 |
| 증빙 필요 | 불필요 | 주요경비에 대한 증빙 필요 |
| 경비율 수준 | 높음 (70~90%) | 낮음 (10~30%) |
| 결과 | 소득이 적게 잡힘 | 소득이 많이 잡힐 수 있음 |
| 무기장가산세 | 없음 | 부과될 수 있음 |

> **실무 팁**: 기준경비율 대상자는 장부를 기장하는 것이 거의 항상 유리하다. 기준경비율로 계산하면 실제보다 소득이 높게 잡히는 경우가 많기 때문이다.

## 개발자가 알아야 할 것 (What Developers Need to Know)

### 시스템 설계에 미치는 영향

1. **소득 유형별 분리 처리**: 종합소득세 시스템은 6가지 소득을 각각 독립적으로 계산한 뒤 합산해야 한다. 소득 유형별로 필요경비 계산 로직이 다르므로, 전략 패턴(Strategy Pattern)이나 다형성으로 분리 설계하는 것이 적절하다.

2. **경비율 테이블 관리**: 단순경비율과 기준경비율은 업종 코드(KSIC)별로 다르며, 매년 국세청이 고시한다. 이 데이터를 외부 설정 테이블로 관리해야 하며, 연도별 버전 관리가 필요하다.

3. **누진세율 계산 엔진**: 과세표준 구간과 세율은 세법 개정에 따라 변경될 수 있으므로, 하드코딩이 아닌 설정 기반 계산 엔진으로 구현해야 한다. 구간별 세율 적용 시 누진공제액 방식으로 계산하면 로직이 단순해진다.

4. **신고 유형 자동 판별**: 사업자의 업종, 수입금액, 기장 방식 등을 기반으로 신고 유형(S, A, B, C, D, E, F, G)을 자동 판별하는 룰 엔진이 필요하다.

5. **분리과세 vs 종합과세 분기**: 이자·배당소득 2,000만 원 기준, 기타소득 300만 원 기준 등 분리과세와 종합과세의 분기 로직을 정확히 구현해야 한다.

### ERP·회계 프로그램 연동 시 참고 사항

- **홈택스 API 연동**: 종합소득세 전자신고 시 홈택스(Hometax)의 세금신고 API와 연동이 필요하다. 신고서 양식 코드, 필드 매핑이 핵심이다.
- **경비율 데이터 갱신**: 국세청이 매년 고시하는 경비율표를 시스템에 반영하는 배치 프로세스가 필요하다.
- **세율표 버전 관리**: 세법 개정 시 세율 구간이 변경되므로, `tax_year` 기준으로 적용 세율표를 분리 관리해야 한다.
- **증빙 관리**: 기준경비율 적용 시 주요경비(매입비용, 인건비, 임차료) 증빙을 관리하는 시스템이 필요하다. 전자세금계산서, 현금영수증 등과의 연동이 핵심이다.

## 용어 사전 (Glossary)

| 한글 | 영문 | 설명 |
|------|------|------|
| 종합소득세 | Comprehensive Income Tax | 개인의 모든 소득을 합산하여 과세하는 세금 |
| 사업소득 | Business Income | 사업 활동에서 발생하는 소득 |
| 총수입금액 | Gross Revenue | 사업으로 발생한 모든 수입의 합계 |
| 필요경비 | Necessary Expenses | 수입을 얻기 위해 지출한 세법상 인정 비용 |
| 소득공제 | Income Deduction | 소득금액에서 차감하여 과세표준을 줄이는 항목 |
| 과세표준 | Tax Base | 세율을 적용하는 기준이 되는 금액 |
| 누진세율 | Progressive Tax Rate | 소득 구간이 높아질수록 세율이 올라가는 체계 |
| 산출세액 | Calculated Tax | 과세표준에 세율을 적용하여 산출한 세액 |
| 세액공제 | Tax Credit | 산출세액에서 직접 차감하는 금액 |
| 결정세액 | Determined Tax | 산출세액에서 세액공제를 차감한 최종 세액 |
| 단순경비율 | Simple Expense Rate | 소규모 사업자의 추계신고 시 적용하는 높은 경비율 |
| 기준경비율 | Standard Expense Rate | 주요경비 증빙 + 나머지 경비율 방식의 추계 경비율 |
| 성실신고확인 | Faithful Tax Return Confirmation | 일정 규모 이상 사업자의 신고 정확성을 세무사가 확인하는 제도 |
| 중간예납 | Interim Payment | 전년도 세액의 절반을 11월에 미리 납부하는 제도 |
| 분리과세 | Separate Taxation | 다른 소득과 합산하지 않고 별도 세율을 적용하는 과세 방식 |
| 원천징수 | Withholding Tax | 소득 지급 시 지급자가 세금을 미리 차감하여 납부하는 제도 |
