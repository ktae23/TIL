## 1. 기장(Bookkeeping)의 개념

### 기장이란 무엇인가

기장(記帳)은 사업과 관련된 모든 거래를 장부에 기록하는 행위다. 세법상 일정 규모 이상의 사업자에게는 장부 작성이 의무이며, 이를 통해 소득금액을 계산하고 세금을 신고한다.

```
┌──────────────────────────────────────────────────────────────────┐
│                    기장의 전체 흐름                                │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│  사업 거래 발생                                                   │
│       │                                                          │
│       ▼                                                          │
│  ┌─────────┐     ┌─────────────┐     ┌──────────────┐           │
│  │ 증빙 수집 │────►│  장부 기록   │────►│ 재무제표 작성 │           │
│  │(영수증등)│     │(간편/복식)  │     │(손익계산서등)│           │
│  └─────────┘     └─────────────┘     └──────────────┘           │
│                                              │                   │
│                                              ▼                   │
│                                     ┌──────────────┐            │
│                                     │  세금 신고    │            │
│                                     │ (종소세 등)   │            │
│                                     └──────────────┘            │
│                                                                   │
│  기장 = 거래 기록 → 장부 작성 → 재무제표 → 세금 신고              │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

### 간편장부 vs 복식부기

세법에서는 사업 규모에 따라 기장 방식을 구분한다.

```
┌──────────────────────────────────────────────────────────────────┐
│              간편장부 vs 복식부기 비교                              │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│  간편장부 (Simple Bookkeeping)                                    │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  날짜 │ 거래내용 │ 수입(매출) │ 비용(매입) │ 비고          │  │
│  │───────┼──────────┼───────────┼───────────┼────────────────│  │
│  │ 01/05 │ 용역제공 │ 1,000,000 │           │ A사 계약       │  │
│  │ 01/10 │ 사무용품 │           │   50,000  │ 프린터 잉크    │  │
│  │ 01/15 │ 통신비   │           │   30,000  │ 인터넷 요금    │  │
│  └────────────────────────────────────────────────────────────┘  │
│  → 가계부 형식, 단순 수입/지출 기록                               │
│                                                                   │
│  복식부기 (Double-entry Bookkeeping)                              │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  날짜 │ 계정과목 │  차변(Debit) │ 대변(Credit)            │  │
│  │───────┼──────────┼─────────────┼─────────────────────────│  │
│  │ 01/05 │ 보통예금 │  1,000,000  │                         │  │
│  │       │ 매출     │             │  1,000,000              │  │
│  │ 01/10 │ 소모품비 │     50,000  │                         │  │
│  │       │ 보통예금 │             │     50,000              │  │
│  └────────────────────────────────────────────────────────────┘  │
│  → 차변/대변 원리, 자산=부채+자본 항등식 유지                     │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

#### 대상자 구분 기준 (직전연도 수입금액 기준)

| 업종 구분 | 간편장부 대상자 | 복식부기 의무자 |
|-----------|----------------|----------------|
| 농업, 임업, 어업, 도소매업, 부동산매매업 | 3억원 미만 | 3억원 이상 |
| 제조업, 숙박업, 음식점업, 건설업, 운수업 | 1억 5천만원 미만 | 1억 5천만원 이상 |
| 부동산임대업, 서비스업, 프리랜서 등 | 7,500만원 미만 | 7,500만원 이상 |
| 전문직 (변호사, 세무사, 회계사 등) | 해당 없음 | 수입 무관, 무조건 복식부기 |

> 신규 사업자는 업종 불문 간편장부 대상자로 분류된다.

### 계정과목 체계

복식부기의 핵심은 모든 거래를 5대 계정과목으로 분류하는 것이다.

```
┌──────────────────────────────────────────────────────────────────┐
│                    5대 계정과목 체계                                │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐ │
│  │         재무상태표 (Balance Sheet) 계정                      │ │
│  │                                                              │ │
│  │  자산(Assets) = 부채(Liabilities) + 자본(Equity)             │ │
│  │                                                              │ │
│  │  [자산]          [부채]          [자본]                       │ │
│  │  현금            미지급금        자본금                       │ │
│  │  보통예금        차입금          이익잉여금                   │ │
│  │  매출채권        선수금          (당기순이익)                 │ │
│  │  재고자산        예수금                                      │ │
│  │  건물/차량       부가세예수금                                 │ │
│  └─────────────────────────────────────────────────────────────┘ │
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐ │
│  │         손익계산서 (Income Statement) 계정                   │ │
│  │                                                              │ │
│  │  수익(Revenue) - 비용(Expense) = 순이익(Net Income)          │ │
│  │                                                              │ │
│  │  [수익]                    [비용]                            │ │
│  │  매출                      매입(매출원가)                    │ │
│  │  이자수익                  급여                              │ │
│  │  임대수익                  임차료                            │ │
│  │                            통신비, 광고비                    │ │
│  │                            감가상각비                        │ │
│  │                            접대비                            │ │
│  └─────────────────────────────────────────────────────────────┘ │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

#### 주요 계정과목 표

| 구분 | 계정과목 | 설명 | 개발 매핑 |
|------|---------|------|-----------|
| 자산 | 현금 | 보유 현금 | `CASH` |
| 자산 | 보통예금 | 은행 계좌 잔고 | `BANK_DEPOSIT` |
| 자산 | 매출채권 | 아직 받지 못한 매출금 | `ACCOUNTS_RECEIVABLE` |
| 자산 | 재고자산 | 판매 대기 상품 | `INVENTORY` |
| 부채 | 미지급금 | 아직 지급하지 않은 비용 | `ACCOUNTS_PAYABLE` |
| 부채 | 예수금 | 원천징수한 세금 | `WITHHOLDING_TAX` |
| 부채 | 선수금 | 미리 받은 대금 | `ADVANCE_RECEIVED` |
| 자본 | 자본금 | 사업 투자금 | `CAPITAL` |
| 수익 | 매출 | 사업으로 번 돈 | `SALES_REVENUE` |
| 비용 | 급여 | 직원 인건비 | `SALARY_EXPENSE` |
| 비용 | 임차료 | 사무실 월세 | `RENT_EXPENSE` |
| 비용 | 감가상각비 | 고정자산 가치 감소분 | `DEPRECIATION` |

### 기장의무자 vs 추계신고

```
┌──────────────────────────────────────────────────────────────────┐
│              기장신고 vs 추계신고 비교                              │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│  기장신고 (장부 기반)                                             │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  실제 수입 - 실제 비용 = 소득금액                           │  │
│  │  → 정확한 세금 계산 가능                                    │  │
│  │  → 기장세액공제 혜택 가능 (간편장부 대상자가 복식부기 시)    │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                   │
│  추계신고 (경비율 기반, 장부 없이 신고)                           │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  ● 단순경비율: 수입 - (수입 x 단순경비율) = 소득금액        │  │
│  │    → 영세사업자 대상 (직전 수입 2,400만원 미만 등)           │  │
│  │                                                             │  │
│  │  ● 기준경비율: 수입 - 주요경비 - (수입 x 기준경비율)        │  │
│  │    = 소득금액                                               │  │
│  │    → 단순경비율 미적용 대상자                                │  │
│  │    → 불리한 경우가 많음 (무기장가산세 20% 부과)              │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                   │
│  결론: 장부를 쓰는 것이 거의 항상 유리                            │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

### 기장세액공제

간편장부 대상자가 자발적으로 복식부기로 신고하면 세액공제를 받을 수 있다.

| 항목 | 내용 |
|------|------|
| 대상 | 간편장부 대상자 중 복식부기로 신고한 사업자 |
| 공제율 | 산출세액의 **20%** |
| 한도 | **연 100만원** |
| 신청 | 기장세액공제신청서 별도 제출 필수 |
| 주의 | 복식부기 의무자는 해당 없음 (의무이므로 공제 불가) |

> AI 기장 서비스의 핵심 가치 중 하나: 간편장부 대상자를 복식부기로 전환시켜 세액공제 혜택을 제공하는 것

## 2. 핵심 세금 종류

### 2-1. 종합소득세 (5월 신고)

종합소득세는 개인이 1년간(1.1~12.31) 벌어들인 모든 소득을 합산하여 신고하는 세금이다.

#### 과세 대상 소득 6가지

```
┌──────────────────────────────────────────────────────────────────┐
│                종합소득세 과세 대상 소득                            │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│  종합소득 = 다음 6가지 소득의 합산                                │
│                                                                   │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                       │
│  │ 사업소득  │  │ 근로소득  │  │ 이자소득  │                       │
│  │(프리랜서) │  │(급여)    │  │(예금이자) │                       │
│  └─────┬────┘  └─────┬────┘  └─────┬────┘                       │
│        │             │             │                              │
│        └──────┬──────┴──────┬──────┘                              │
│               │             │                                     │
│  ┌──────────┐ │  ┌──────────┤  ┌──────────┐                     │
│  │ 배당소득  │─┘  │ 연금소득  │  │ 기타소득  │                     │
│  │(주식배당) │    │(개인연금) │  │(강연료등) │                     │
│  └──────────┘    └──────────┘  └─────┬────┘                     │
│                                       │                           │
│                       ┌───────────────┘                           │
│                       ▼                                           │
│              ┌──────────────┐                                    │
│              │  종합소득금액  │                                    │
│              └──────────────┘                                    │
│                                                                   │
│  ※ 세무 플랫폼 주요 타겟: 사업소득(프리랜서), 기타소득                 │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

#### 8단계 누진세율 (2024년 귀속, 2025년 5월 신고 기준)

| 과세표준 구간 | 세율 | 누진공제 |
|-------------|------|---------|
| 1,400만원 이하 | 6% | - |
| 1,400만원 초과 ~ 5,000만원 이하 | 15% | 126만원 |
| 5,000만원 초과 ~ 8,800만원 이하 | 24% | 576만원 |
| 8,800만원 초과 ~ 1억 5천만원 이하 | 35% | 1,544만원 |
| 1억 5천만원 초과 ~ 3억원 이하 | 38% | 1,994만원 |
| 3억원 초과 ~ 5억원 이하 | 40% | 2,594만원 |
| 5억원 초과 ~ 10억원 이하 | 42% | 3,594만원 |
| 10억원 초과 | 45% | 6,594만원 |

> 과세표준 1,200만원 → 1,400만원으로 6% 구간이 확대된 것이 최근 개정 핵심

#### 종합소득세 계산 흐름

```
┌──────────────────────────────────────────────────────────────────┐
│              종합소득세 계산 흐름 (Tax Calculation Pipeline)        │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│  [1] 총수입금액 (Gross Income)                                    │
│       │                                                          │
│       │  (-) 필요경비 (Deductible Expenses)                       │
│       ▼                                                          │
│  [2] 소득금액 (Net Income)                                        │
│       │                                                          │
│       │  (-) 소득공제 (Income Deductions)                         │
│       │      - 인적공제 (본인, 배우자, 부양가족)                   │
│       │      - 국민연금, 건강보험료 공제                           │
│       │      - 주택자금공제 등                                    │
│       ▼                                                          │
│  [3] 과세표준 (Taxable Income)                                    │
│       │                                                          │
│       │  (x) 세율 적용 (8단계 누진세율)                           │
│       ▼                                                          │
│  [4] 산출세액 (Calculated Tax)                                    │
│       │                                                          │
│       │  (-) 세액공제 (Tax Credits)                               │
│       │      - 기장세액공제, 자녀세액공제                         │
│       │      - 전자신고세액공제 (2만원)                            │
│       │      - 표준세액공제 (7만원)                                │
│       ▼                                                          │
│  [5] 결정세액 (Determined Tax)                                    │
│       │                                                          │
│       │  (-) 기납부세액 (Prepaid Tax)                             │
│       │      - 원천징수세액 (3.3% 등)                             │
│       │      - 중간예납세액                                       │
│       ▼                                                          │
│  [6] 납부할 세액 (또는 환급세액)                                   │
│       │                                                          │
│       ├── 양수(+) → 추가 납부                                    │
│       └── 음수(-) → 환급 발생!  ← 세무 플랫폼 핵심 서비스              │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

#### 계산 예시

```
프리랜서 김개발 (연 수입 5,000만원, 필요경비 2,000만원)

총수입금액:       50,000,000원
(-) 필요경비:    -20,000,000원
─────────────────────────────
소득금액:         30,000,000원
(-) 소득공제:     -5,000,000원 (인적공제 등)
─────────────────────────────
과세표준:         25,000,000원

산출세액: 25,000,000 x 15% - 1,260,000(누진공제)
        = 3,750,000 - 1,260,000
        = 2,490,000원

(-) 세액공제:       -20,000원 (전자신고)
─────────────────────────────
결정세액:          2,470,000원

(-) 기납부세액:   -1,500,000원 (원천징수 3.3%로 납부한 금액)
─────────────────────────────
납부할 세액:         970,000원

※ 만약 기납부세액이 결정세액보다 크면 → 환급 발생
```

### 2-2. 부가가치세 (1월, 7월 신고)

부가가치세(VAT)는 재화나 용역의 거래 단계마다 부가되는 가치에 대해 부과하는 세금이다.

#### 핵심 계산 구조

```
┌──────────────────────────────────────────────────────────────────┐

## 3. 환급 구조와 경정청구

### 환급이 발생하는 경우

```
환급 = 기납부세액(미리 낸 세금) > 결정세액(실제 내야 할 세금)

대표적 환급 발생 케이스:
 1. 원천징수(3.3%)로 미리 많이 납부한 경우
 2. 소득공제/세액공제를 누락하여 세금을 과다 납부한 경우
 3. 필요경비를 인정받지 못해 소득이 과대 계상된 경우
 4. 중간예납세액이 실제 세액보다 큰 경우
```

### 경정청구란

경정청구는 이미 신고한 세금이 과다 납부되었을 때, 이를 바로잡아 돌려달라고 요청하는 제도다.

| 항목 | 내용 |
|------|------|
| 근거 법령 | 국세기본법 제45조의2 |
| 청구 기한 | 법정신고기한으로부터 **5년 이내** |
| 대상 | 과다 납부한 모든 국세 |
| 처리 기한 | 청구일로부터 2개월 이내 (세무서) |
| 환급 방법 | 신청 계좌로 입금 |

> 세무 플랫폼 핵심 서비스: 지난 5년치 세금 신고를 분석하여 환급 가능한 금액을 자동 계산하고 경정청구를 대행

#### 종합소득세 세율 계산기

/**
 * 종합소득세 누진세율 계산기
 * 2024년 귀속 기준 (2025년 5월 신고)
 */
public class IncomeTaxCalculator {

    private static final List<TaxBracket> BRACKETS = List.of(
        new TaxBracket(0L,            14_000_000L,  0.06, 0L),
        new TaxBracket(14_000_000L,   50_000_000L,  0.15, 1_260_000L),
        new TaxBracket(50_000_000L,   88_000_000L,  0.24, 5_760_000L),
        new TaxBracket(88_000_000L,  150_000_000L,  0.35, 15_440_000L),
        new TaxBracket(150_000_000L, 300_000_000L,  0.38, 19_940_000L),
        new TaxBracket(300_000_000L, 500_000_000L,  0.40, 25_940_000L),
        new TaxBracket(500_000_000L, 1_000_000_000L, 0.42, 35_940_000L),
        new TaxBracket(1_000_000_000L, Long.MAX_VALUE, 0.45, 65_940_000L)
    );

    /**
     * 과세표준에 대한 산출세액 계산
     * 산출세액 = 과세표준 x 세율 - 누진공제
     */
    public static long calculateTax(long taxableIncome) {
        if (taxableIncome <= 0) return 0;

        return BRACKETS.stream()
            .filter(b -> taxableIncome > b.lowerBound())
            .reduce((first, second) -> second)  // 가장 높은 구간
            .map(b -> (long)(taxableIncome * b.rate()) - b.progressiveDeduction())
            .orElse(0L);
    }

    record TaxBracket(
        long lowerBound,
        long upperBound,
        double rate,
        long progressiveDeduction
    ) {}
}
```

#### 원천징수 계산

```java
/**
 * 원천징수 계산 서비스
 */
@Service
public class WithholdingTaxService {

    private static final double INCOME_TAX_RATE = 0.03;        // 소득세 3%
    private static final double LOCAL_TAX_RATE = 0.003;         // 지방소득세 0.3%
    private static final double TOTAL_RATE = 0.033;             // 합계 3.3%

    /**
     * 사업소득(프리랜서) 원천징수액 계산
     */
    public WithholdingResult calculate(long paymentAmount) {
        long incomeTax = Math.round(paymentAmount * INCOME_TAX_RATE);
        long localTax = Math.round(paymentAmount * LOCAL_TAX_RATE);
        long totalWithholding = incomeTax + localTax;
        long netPayment = paymentAmount - totalWithholding;

        return new WithholdingResult(
            paymentAmount, incomeTax, localTax, totalWithholding, netPayment
        );
    }

    record WithholdingResult(
        long grossPayment,      // 계약금액
        long incomeTax,         // 소득세 (3%)
        long localTax,          // 지방소득세 (0.3%)
        long totalWithholding,  // 원천징수 합계 (3.3%)
        long netPayment         // 실수령액
    ) {}
}

### AI 세무 플랫폼의 대응 방식

```
세무 플랫폼의 법적 구조:

  사용자 ──► 세무 플랫폼 ──► 제휴 세무사 ──► 국세청(홈택스)
              (IT 플랫폼)     (세무대리인)     (세금 신고)

  핵심 논리:
  1. 플랫폼은 "IT 서비스"이지 세무대리인이 아님
  2. 실제 세무 신고는 제휴 세무사가 수행
  3. AI는 데이터 분석 도구로서 세무사를 보조
  4. 검찰도 적법성 인정 (불기소 처분)
```

### 2026년 세무사법 개정 동향

2026년 1월 개정된 세무사법은 플랫폼 사업자의 세무서비스 광고 규정을 강화하여, 무자격자가 세무대리업무를 취급하는 것으로 오인될 우려가 있는 표시/광고를 금지했다. 이에 따라 AI 세무 플랫폼들은 서비스 표현 방식을 조정할 필요가 생겼다.

│  2. 종합소득세 = 6가지 소득 합산 → 누진세율 적용                  │
│     - 8단계 세율 (6% ~ 45%)                                      │
│     - 5월 확정 신고                                               │
│                                                                   │
│  3. 부가가치세 = 매출세액 - 매입세액                              │
│     - 일반 10% vs 간이 1.5~4%                                    │
│     - 1월, 7월 신고                                               │
│                                                                   │
│  4. 원천징수 3.3% = 소득세 3% + 지방소득세 0.3%                   │
│     - 프리랜서 소득 지급 시 선공제                                │
│     - 5월 종소세 신고 시 기납부세액으로 정산                      │
│                                                                   │
│  5. 경정청구 = 과다 납부 세금 돌려달라는 요청                     │
│     - 법정신고기한으로부터 5년 이내                                │
│     - AI 세무 플랫폼 환급 서비스의 법적 근거                      │
│                                                                   │
│  6. AI 세무 플랫폼 = 대규모 세금 환급/기장 서비스                │
│     - 수익 모델: 환급 수수료 (0~20%)                              │
│     - 제휴 세무사 연계로 법적 리스크 관리                         │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

## 실무 기반 핵심 질문

### Q1: AI 세무 플랫폼의 비즈니스 모델을 설명해주세요.

**A:** AI 세무 플랫폼은 프리랜서 사업소득의 **3.3% 원천징수**(소득세 3% + 지방소득세 0.3%)를 핵심으로 합니다. 프리랜서가 용역 대가를 받을 때 3.3%가 선공제되는데, 이 원천징수세액이 실제 결정세액보다 많으면 환급이 발생합니다. 플랫폼은 홈택스 데이터를 스크래핑하여 AI로 환급 가능 금액을 분석하고, 제휴 세무사를 통해 경정청구/종소세 신고를 대행합니다. 수익 모델은 환급액의 0~20% 수수료입니다.

### Q2: 종합소득세 계산 흐름을 설명해주세요.

**A:** 총수입금액에서 필요경비를 차감하여 소득금액을 구하고, 여기서 인적공제 등 소득공제를 빼면 과세표준이 됩니다. 과세표준에 8단계 누진세율(6%~45%)을 적용하면 산출세액이 나오고, 세액공제를 차감하면 결정세액입니다. 최종적으로 원천징수 등 기납부세액을 빼면 납부할 세액 또는 환급세액이 결정됩니다. 세무 플랫폼의 핵심은 이 파이프라인에서 누락된 공제 항목을 찾아 환급세액을 최대화하는 것입니다.

### Q3: 간편장부와 복식부기의 차이점은 무엇인가요?

**A:** 간편장부는 가계부 형식으로 수입/지출을 단순 기록하는 방식이고, 복식부기는 모든 거래를 차변/대변으로 이중 기록하여 자산=부채+자본 항등식을 유지하는 방식입니다. 업종별로 직전연도 수입금액 기준(서비스업 7,500만원, 제조업 1.5억, 도소매업 3억 이상)에 따라 복식부기 의무 여부가 결정됩니다. 간편장부 대상자가 자발적으로 복식부기로 신고하면 산출세액의 20%(한도 100만원)를 기장세액공제로 받을 수 있습니다.

### Q4: 부가가치세에서 일반과세자와 간이과세자의 차이는?

**A:** 2025년 기준, 연 매출 1억 400만원을 기준으로 구분됩니다. 일반과세자는 10% 세율로 매출세액-매입세액을 계산하며 연 2회(1월, 7월) 신고합니다. 간이과세자는 업종별 1.5~4%의 낮은 세율이 적용되며 연 1회(1월) 신고합니다. 간이과세자 중 연 매출 4,800만원 미만은 부가세 납부가 면제되고, 세금계산서 발행도 불가합니다.

### Q5: 경정청구란 무엇이고, 세무 플랫폼과의 관계는?

**A:** 경정청구는 국세기본법 제45조의2에 따라 과다 납부한 세금을 바로잡아 환급받는 제도로, 법정신고기한으로부터 5년 이내에 가능합니다. AI 세무 플랫폼은 사용자의 과거 5년치 홈택스 신고 데이터를 분석하여 누락된 공제나 과다 계상된 소득을 발견하고, 제휴 세무사를 통해 경정청구를 진행합니다. 이것이 환급 서비스의 핵심 메커니즘입니다.

### Q6: 세무사법 이슈에 대해 어떻게 이해하고 있나요?

**A:** 세무사법은 비세무사의 세무대리를 금지하고 있어, AI 세무 플랫폼의 법적 경계가 논쟁의 대상입니다. 한국세무사회는 AI 자동신고가 무자격 세무대리에 해당한다고 주장하며 여러 차례 고발했지만, 검찰은 불기소 처분을 내렸고 항고/재항고도 기각되었습니다. AI 세무 플랫폼들은 "IT 플랫폼 + 제휴 세무사" 구조를 통해 법적 리스크를 관리하고 있으며, 2026년 개정 세무사법에 따른 광고 규정 변화에도 대응하고 있습니다.

### Q7: 개발자로서 세무 도메인을 코드로 어떻게 모델링하겠습니까?

**A:** 핵심 도메인 개념을 Enum으로 명확히 정의하겠습니다. TaxType(세금 종류), IncomeCategory(소득 유형 + 원천징수 세율), AccountType(계정과목 + 5대 분류)을 Enum으로 설계하고, IncomeTaxReturn Entity로 종소세 신고의 전체 계산 파이프라인(총수입→결정세액→환급)을 모델링합니다. 특히 종합소득세 누진세율 계산은 TaxBracket record를 사용한 계산기 클래스로 캡슐화하여, 세율 변경 시 데이터만 수정하면 되도록 설계합니다.

### Q8: 세무 플랫폼 서비스에서 5월 종소세 시즌 트래픽 대응은 어떻게 해야 할까요?

**A:** 5월은 세무 플랫폼의 최대 피크 시즌으로, 몇 가지 전략이 필요합니다. 첫째, 홈택스 스크래핑은 외부 시스템 의존도가 높으므로 비동기 처리와 재시도 메커니즘이 핵심입니다. 둘째, 세금 계산은 사용자별 독립적이므로 수평 확장(scale-out)에 적합하며, Spring Batch를 활용한 대량 배치 처리가 효과적입니다. 셋째, 계산 결과 캐싱으로 동일 조건 재요청을 최소화하고, 넷째, 사전 마케팅(4월)으로 트래픽을 분산시키는 것도 인프라 비용 절감에 도움이 됩니다.

### Q9: 원천징수 3.3%로 원천징수된 세금이 환급되는 원리를 설명해주세요.

**A:** 원천징수 3.3%는 소득 발생 시점에 미리 납부하는 세금입니다. 연간 총소득에 대해 종합소득세를 계산하면 실제 결정세액이 나오는데, 이미 원천징수로 납부한 기납부세액이 결정세액보다 크면 차액이 환급됩니다. 특히 프리랜서의 소득이 적거나, 필요경비가 많거나, 소득공제/세액공제 항목이 많은 경우 환급이 발생할 확률이 높습니다. AI 세무 플랫폼은 바로 이 차액을 자동으로 계산하여 환급 신청을 도와주는 서비스입니다.

### Q10: AI 기장 서비스가 기존 세무사 사무소와 어떻게 다른가요?

**A:** 전통적인 세무사 사무소는 담당 세무사가 수동으로 장부를 기록하고 신고하는 반면, AI 기장 서비스는 자동화를 통해 대량의 기장 업무를 처리합니다. 홈택스/카드사/은행 데이터를 자동 수집하여 거래를 분류하고, AI가 계정과목을 추천하며, 세무사가 최종 검토하는 구조입니다. 이를 통해 비용은 낮추면서 대규모 사용자를 동시에 서비스할 수 있습니다. 개발 관점에서는 데이터 파이프라인, 배치 처리, ML 분류 모델이 핵심 기술 요소입니다.
