# 세무기장 실무 워크플로우 (Tax Bookkeeping Workflow)

> 📚 **선수 지식**: [세무기장이란](./tax-bookkeeping-intro.md), [증빙 관리와 적격증빙](./tax-evidence-management.md), [원천징수 실무](./withholding-tax.md)

## 개요

세무기장 실무는 단순히 장부를 기록하는 작업이 아니라, 매일·매월·분기·연간 단위로 반복되는 정형화된 워크플로우 (Workflow) 로 구성된다. 세무기장 담당자 (기장 실무자 또는 세무사 사무실 직원) 는 이 사이클을 정확히 이해하고, 각 시점에 해야 할 업무를 놓치지 않는 것이 핵심 역량이다.

특히 대한민국의 세무 신고 기한 (Filing Deadline) 은 법으로 정해져 있으며, 이를 어기면 가산세 (Surcharge / Penalty Tax) 가 부과된다. 따라서 연간 세무 캘린더를 숙지하고, 체계적인 업무 관리 시스템을 갖추는 것이 필수적이다.

## 세무기장 연간 업무 사이클 (Annual Tax Calendar)

세무기장의 연간 사이클은 크게 월별 정기 업무, 분기별 업무, 연간 업무로 나뉜다.

### 월별 정기 업무

매월 반복되는 기본 업무로, 세무기장의 뼈대를 이루는 작업이다:

1. **전표 입력 (Voucher Entry)**: 거래 증빙을 바탕으로 회계 전표를 작성·입력
2. **증빙 정리 (Evidence Organization)**: 수취한 증빙서류를 분류·정리·보관
3. **원천세 신고·납부 (Withholding Tax Filing & Payment)**: 매월 10일까지 전월분 원천세 신고·납부
4. **4대 보험 (Social Insurance) 관련 업무**: 취득·상실 신고, 보수월액 변경 등
5. **급여 처리 (Payroll Processing)**: 급여 계산, 급여대장 작성, 급여 이체

### 분기별 업무

- 부가가치세 (VAT) 예정·확정 신고 (분기별 해당 시)
- 분기별 재무제표 (Quarterly Financial Statements) 작성 및 검토
- 일용근로소득 지급명세서 제출 (분기별)

### 연간 업무

- 결산 (Year-end Closing / Settlement of Accounts)
- 법인세 (Corporate Tax) 또는 종합소득세 (Comprehensive Income Tax) 신고
- 연말정산 (Year-end Tax Settlement)
- 각종 지급명세서 (Payment Statement) 제출
- 사업장현황신고 (면세사업자)

## 월별 업무 상세

### 매월 반복 업무

#### 전표 입력 (Voucher Entry) — 매일/매주

모든 세무기장의 기초가 되는 업무이다. 사업에서 발생하는 모든 거래를 회계 전표로 기록한다.

**전표 입력 프로세스:**
1. 증빙 수취 → 2. 증빙 분류 → 3. 계정과목 (Account Title) 결정 → 4. 전표 작성 → 5. 입력·검증

**주요 전표 유형:**
- 입금전표 (Receipt Voucher): 현금이 들어오는 거래
- 출금전표 (Disbursement Voucher): 현금이 나가는 거래
- 대체전표 (Transfer Voucher): 현금의 수수가 없는 거래 (감가상각 등)

#### 원천세 신고 (Withholding Tax Filing) — 매월 10일

매월 10일까지 전월에 원천징수 (Withholding) 한 세금을 신고·납부한다.

**원천세 신고 대상:**
- 근로소득 (Earned Income) : 급여에서 원천징수한 소득세·지방소득세
- 사업소득 (Business Income) : 프리랜서 등에게 지급한 금액의 3.3% (소득세 3% + 지방소득세 0.3%)
- 기타소득 (Other Income) : 강연료, 원고료 등
- 퇴직소득 (Retirement Income) : 퇴직금 지급 시
- 이자·배당소득 (Interest & Dividend Income)

**반기 납부 (Semi-annual Payment) 특례:**
상시근로자 수가 20인 이하인 소규모 사업장은 원천세를 반기별 (7월 10일, 1월 10일) 로 납부할 수 있다.

#### 증빙 정리 — 수시 / 매월

증빙을 월별로 정리하고 분류하는 작업이다.

**증빙 정리 순서:**
1. 날짜순 정렬
2. 증빙 유형별 분류 (세금계산서, 카드전표, 현금영수증 등)
3. 사업 관련성 확인 (사적 경비 분리)
4. 누락 증빙 확인 및 요청
5. 스캔 및 디지털 보관

### 1월 업무

1월은 연간 세무 업무의 시작이자 가장 바쁜 달 중 하나이다.

| 업무 | 기한 | 내용 |
|------|------|------|
| 원천세 신고 (12월분) | 1월 10일 | 전월 원천징수분 신고·납부 |
| 부가가치세 확정신고 (2기) | 1월 25일 | 7~12월분 부가세 확정신고 |
| 면세사업자 사업장현황신고 | 2월 10일 (1월 준비) | 면세사업자의 연간 매출·매입 현황 신고 |
| 지급명세서 제출 | 3월 10일 (1월 준비 시작) | 근로·사업·기타소득 지급명세서 |
| 일용근로소득 지급명세서 | 1월 말 | 전분기 (10~12월) 일용직 지급명세서 |

**부가가치세 확정신고 (2기) 상세:**
- 신고 기간: 7월 1일 ~ 12월 31일 공급분
- 신고·납부 기한: 다음 해 1월 25일
- 매출세금계산서 합계표 (Sales Tax Invoice Summary) 와 매입세금계산서 합계표 (Purchase Tax Invoice Summary) 작성
- 매출세액 (Output Tax) 에서 매입세액 (Input Tax) 을 차감하여 납부세액 계산

| 근로소득 지급명세서 제출 | 3월 10일 | 전년도 근로소득 지급명세서 |

**법인세 신고 상세:**
- 12월 결산법인 (대부분의 법인) 은 다음 해 3월 31일까지 법인세를 신고·납부
- 세무조정계산서 (Tax Adjustment Report) 작성 필요
- 재무제표 확정 및 주주총회 (General Meeting of Shareholders) 승인

- 개인사업자는 예정고지 (Preliminary Notice) 로 대체 가능 (직전 확정신고세액의 50%)
- 법인사업자는 예정신고 의무

| **4월** | 부가세 예정신고 (1기) | 25일 |

| **6월** | 성실신고확인서 제출 (해당자) | 30일 |
| **7월** | 부가세 확정신고 (1기) | 25일 |
| **8월** | 법인세 중간예납 | 31일 |
| **10월** | 부가세 예정신고 (2기) | 25일 |
| **12월** | 연말정산 준비 | 31일 |

### 부가가치세 신고 사이클

```
1기 예정: 1~3월분 → 4월 25일 신고
1기 확정: 1~6월분 → 7월 25일 신고
2기 예정: 7~9월분 → 10월 25일 신고
2기 확정: 7~12월분 → 다음 해 1월 25일 신고
```

### 원천세 신고 사이클

```
일반: 매월 10일 (전월분)
반기 특례: 7월 10일 (1~6월분), 1월 10일 (7~12월분)
```

## 실무 체크리스트

### 일일 업무 (Daily Tasks)

- [ ] 당일 발생 거래 확인 및 전표 입력
- [ ] 통장 입출금 내역 확인 (Bank Reconciliation)
- [ ] 수취 증빙 확인 및 정리
- [ ] 매출·매입 세금계산서 발행·수취 확인
- [ ] 현금영수증 발행 확인

### 주간 업무 (Weekly Tasks)

- [ ] 주간 매출·매입 집계 및 검토
- [ ] 미처리 전표 확인 및 입력
- [ ] 미수금 (Accounts Receivable) / 미지급금 (Accounts Payable) 현황 점검
- [ ] 카드 매출 정산 확인 (Card Settlement Verification)
- [ ] 누락 증빙 확인 및 거래처에 요청

### 월말 업무 (Month-end Tasks)

- [ ] 월말 전표 마감 (Monthly Closing)
- [ ] 월별 시산표 (Trial Balance) 작성 및 검증
- [ ] 차변·대변 합계 일치 확인
- [ ] 통장 잔액과 장부 잔액 대사 (Bank Reconciliation)
- [ ] 매출·매입 장부와 세금계산서 합계 대사
- [ ] 급여 계산 및 급여대장 작성
- [ ] 원천세 신고 준비 (다음 달 10일 기한)
- [ ] 4대 보험 취득·상실 처리
- [ ] 월별 재무제표 검토 (필요시)

### 분기말 업무 (Quarter-end Tasks)

- [ ] 분기별 재무제표 작성 및 검토
- [ ] 부가가치세 신고 준비 (해당 분기)
- [ ] 매출·매입 세금계산서 합계표 작성
- [ ] 부가세 예정/확정 신고·납부
- [ ] 일용근로소득 지급명세서 제출
- [ ] 분기별 경영 실적 분석 보고서 작성 (해당 시)

### 결산 업무 (Year-end Closing Tasks)

- [ ] 재고자산 실사 (Inventory Count) — 12월 말
- [ ] 감가상각비 (Depreciation) 계산 및 반영
- [ ] 대손충당금 (Allowance for Bad Debts) 설정
- [ ] 미지급비용 (Accrued Expenses) 반영
- [ ] 선급비용 (Prepaid Expenses) 정리
- [ ] 가지급금 (Temporary Payment) / 가수금 (Temporary Receipt) 정리
- [ ] 퇴직급여충당부채 (Provision for Retirement Benefits) 설정
- [ ] 결산 분개 (Closing Journal Entries) 입력
- [ ] 최종 시산표 (Final Trial Balance) 작성
- [ ] 재무상태표 (Balance Sheet) 확정
- [ ] 손익계산서 (Income Statement) 확정
- [ ] 이익잉여금처분계산서 (Statement of Retained Earnings) 작성 (법인)
- [ ] 세무조정 (Tax Adjustment) 수행
- [ ] 법인세 / 종합소득세 신고서 작성

## 세무 프로그램 활용

### 주요 세무 프로그램

세무기장 실무에서 사용하는 프로그램은 크게 세무사 사무실용과 자체기장용으로 나뉜다.

#### 세무사 사무실용 프로그램

| 프로그램 | 개발사 | 특징 |
|----------|--------|------|
| **더존 Smart A** (Douzone Smart A) | 더존비즈온 (Douzone Bizon) | 시장점유율 1위, 가장 많이 사용되는 세무회계 프로그램. 세무사 사무실 표준. |
| **세무사랑** (Taxmate / Tax Sarang) | 한길IT | 더존과 함께 양대 산맥. 직관적 UI, 빠른 처리 속도. |
| **이택스** (eTax) | 이지텍 (Easytek) | 중소 세무사 사무실에서 사용. 비용 효율적. |

#### 기업 자체기장용 프로그램 (ERP)

### 프로그램 선택 시 고려사항

1. **사업 규모와 복잡도**
   - 소규모 개인사업자: 삼쩜삼, SSEM, 캐시노트 등 간편 서비스
   - 중규모 사업자: 위하고, 얼마에요 등 자체기장용 ERP
   - 세무사 사무실: 더존 Smart A 또는 세무사랑

2. **업종 특성**
   - 제조업: 원가계산 (Cost Accounting) 기능이 필요 → ERP 시스템
   - 유통업: 재고관리 (Inventory Management) 연동 필요
   - 서비스업: 상대적으로 간단한 프로그램으로 충분

3. **연동 기능**
   - 홈택스 연동 (전자세금계산서 자동 수집)
   - 은행 연동 (통장 거래내역 자동 수집)
   - 카드사 연동 (카드 사용 내역 자동 수집)
   - 4대 보험 연동

4. **비용 구조**
   - 설치형 vs 클라우드 (SaaS)
   - 초기 구매비용 vs 월 이용료
   - 사용자 수에 따른 요금 체계
   - 기능 확장 시 추가 비용

5. **기술 지원**
   - 교육 프로그램 제공 여부
   - 고객지원 응대 품질
   - 법규 변경 시 업데이트 속도

   - 세무 관련 내용을 비전문가에게 설명하는 능력

### 개발자가 알아야 할 것 (What Developers Need to Know)

#### 시스템 설계 시 고려사항

1. **세무 캘린더 엔진**: 사업자 유형 (법인/개인, 과세/면세) 에 따라 해당 신고 일정을 자동으로 생성하고, D-day 알림을 제공하는 엔진이 필요하다. 공휴일·주말에 따른 기한 연장 로직도 포함해야 한다.

2. **워크플로우 상태 관리**: 각 신고·업무의 상태 (미착수 / 진행 중 / 완료 / 지연) 를 추적하는 상태 머신 (State Machine) 이 필요하다. 복수의 거래처를 관리하는 세무사 사무실에서는 거래처별 워크플로우 대시보드가 핵심 기능이다.

3. **자동 전표 생성**: 은행 거래내역, 카드사 사용내역, 전자세금계산서 데이터를 수집하여 자동으로 전표를 생성하는 기능은 기장 업무의 효율을 크게 높인다. 머신러닝 (Machine Learning) 을 활용한 계정과목 자동 추천도 트렌드이다.

4. **신고서 자동 작성**: 장부 데이터를 바탕으로 각종 세무 신고서 양식을 자동으로 채우는 기능이 필요하다. 신고서 양식은 국세청에서 매년 업데이트하므로, 양식 변경에 유연하게 대응할 수 있는 구조가 중요하다.

5. **체크리스트 관리 시스템**: 일일/주간/월말/분기말/결산 체크리스트를 관리하고, 완료 여부를 추적하며, 담당자를 할당하는 태스크 관리 기능이 세무 프로그램의 품질을 좌우한다.

6. **멀티 테넌트 설계**: 세무사 사무실은 수십~수백 개의 거래처를 동시에 관리한다. 거래처별 데이터 격리 (Tenant Isolation) 와 동시에 사무실 차원의 통합 뷰를 제공하는 멀티 테넌트 (Multi-tenant) 아키텍처가 필수적이다.

#### 데이터 모델링 포인트

```
TaxCalendar (세무 캘린더)
├── id
├── taxpayer_id: 사업자 ID
├── filing_type: VAT_PRELIMINARY | VAT_FINAL | CORPORATE_TAX | INCOME_TAX | WITHHOLDING | ...
├── tax_period_start / tax_period_end: 과세 기간
├── filing_deadline: 신고 기한
├── status: NOT_STARTED | IN_PROGRESS | FILED | OVERDUE
├── filed_at: 실제 신고일시
├── assigned_to: 담당자
└── notes: 비고

WorkflowChecklist (업무 체크리스트)
├── id
├── taxpayer_id
├── checklist_type: DAILY | WEEKLY | MONTHLY | QUARTERLY | YEAR_END
├── period: 해당 기간 (YYYY-MM 등)
├── items: JSON (체크 항목 목록 및 완료 여부)
├── assigned_to: 담당자
└── completed_at

JournalEntry (전표)
├── id
├── taxpayer_id
├── entry_date: 전표 일자
├── entry_type: RECEIPT | DISBURSEMENT | TRANSFER
├── debit_account: 차변 계정과목
├── credit_account: 대변 계정과목
├── amount: 금액
├── description: 적요
├── evidence_id: 증빙 ID (FK)
├── source: MANUAL | AUTO_BANK | AUTO_CARD | AUTO_ETAX
├── is_closing_entry: 결산 분개 여부
└── created_by / approved_by
```

### 용어 사전 (Glossary)

| 한글 | 영문 | 설명 |
|------|------|------|
| 전표 입력 | Voucher Entry | 거래 증빙을 바탕으로 회계 전표를 작성하여 장부에 기록하는 작업 |
| 원천세 신고 | Withholding Tax Filing | 급여·사업소득 등에서 원천징수한 세금을 매월 10일까지 신고·납부하는 업무 |
| 부가가치세 신고 | VAT Filing | 분기별로 매출세액과 매입세액을 정산하여 신고·납부하는 업무 |
| 결산 | Year-end Closing | 회계기간 말에 장부를 마감하고 재무제표를 확정하는 절차 |
| 세무조정 | Tax Adjustment | 기업회계기준에 따른 이익을 세법 기준의 과세소득으로 조정하는 과정 |
| 시산표 | Trial Balance | 모든 계정의 차변·대변 합계가 일치하는지 검증하는 표 |
| 감가상각 | Depreciation | 고정자산의 취득원가를 내용연수에 걸쳐 비용으로 배분하는 절차 |
| 대손충당금 | Allowance for Bad Debts | 회수 불가능한 채권에 대비하여 미리 설정하는 충당금 |
| 법인세 중간예납 | Corporate Tax Interim Payment | 사업연도 중간에 법인세의 일부를 미리 납부하는 제도 |
| 연말정산 | Year-end Tax Settlement | 근로소득자의 1년간 소득세를 정산하여 과부족을 조정하는 절차 |
| 지급명세서 | Payment Statement | 소득을 지급한 사실을 국세청에 보고하는 서류 |
| 사업장현황신고 | Business Status Report | 면세사업자가 연간 매출·매입 현황을 신고하는 제도 |
