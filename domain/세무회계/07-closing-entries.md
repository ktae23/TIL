# 결산과 수정분개 (Closing Entries and Adjusting Entries)

> 📚 **선수 지식**: [분개와 전기](./04-journal-entries.md), [재무상태표](./05-balance-sheet.md), [손익계산서](./06-income-statement.md)

## 결산이란 무엇인가

결산 (Closing)이란 **회계기간 (Fiscal Period)이 끝날 때 재무제표를 확정하기 위해 수행하는 일련의 절차**이다. 일상적인 거래를 기록하는 것이 기중 (During the Period) 회계라면, 결산은 기말 (End of Period) 회계에 해당한다.

사업체는 보통 매년 1회 결산을 수행하지만 (연차 결산), 분기별 또는 월별로 중간 결산을 하기도 한다. 법인은 사업연도 종료 후 3개월 이내에 법인세를 신고해야 하므로, 결산은 세무 신고의 전제 조건이다.

### 결산의 목적

1. **재무제표 확정**: 재무상태표, 손익계산서 등을 정확하게 완성한다
2. **수익·비용의 정확한 기간 배분**: 발생주의 (Accrual Basis)에 따라 해당 기간에 귀속되는 수익과 비용을 정확히 배분한다
3. **세무 신고 준비**: 법인세 또는 소득세 신고를 위한 과세소득을 확정한다
4. **장부 마감**: 당기 손익 계정을 마감하고 다음 기로 이월할 준비를 한다

---

## 결산 절차 전체 흐름

결산은 다음과 같은 순서로 진행된다:

```
1. 수정 전 시산표 (Unadjusted Trial Balance) 작성
         ↓
2. 수정분개 (Adjusting Entries) 작성 및 전기
         ↓
3. 수정 후 시산표 (Adjusted Trial Balance) 작성
         ↓
4. 재무제표 (Financial Statements) 작성
         ↓
5. 결산 마감 분개 (Closing Entries) 작성 및 전기
         ↓
6. 이월시산표 (Post-closing Trial Balance) 작성
```

### 1단계: 수정 전 시산표 작성

수정 전 시산표 (Unadjusted Trial Balance)는 기중에 기록한 모든 분개의 결과를 정리한 것이다. 총계정원장 (General Ledger)의 각 계정 잔액을 한 곳에 모아 차변 합계와 대변 합계가 일치하는지 확인한다.

이 시점에서는 아직 기말 수정사항이 반영되지 않았으므로, 일부 계정의 잔액이 정확하지 않을 수 있다.

### 2단계: 수정분개 작성

아래에서 상세히 다룬다.

### 3단계: 수정 후 시산표 작성

수정분개를 전기한 후의 시산표이다. 모든 수정사항이 반영되었으므로, 이 시산표의 잔액으로 재무제표를 작성할 수 있다.

### 4단계: 재무제표 작성

수정 후 시산표를 기초로 재무상태표, 손익계산서 등을 작성한다.

## 수정분개 (Adjusting Entries)

### 수정분개가 필요한 이유

기중에 발생한 모든 거래가 실시간으로 기록되는 것은 아니다. 또한 시간의 경과에 따라 점진적으로 발생하는 수익이나 비용은 기말에 한꺼번에 인식해야 할 때가 있다. 수정분개 (Adjusting Entries)는 이러한 항목들을 발생주의 원칙에 맞게 조정하는 분개이다.

### 수정분개의 유형

수정분개는 크게 4가지 유형으로 나눌 수 있다:

| 유형 | 설명 | 방향 |
|------|------|------|
| 미지급비용 (Accrued Expenses) | 발생했지만 아직 지급하지 않은 비용 | 비용 증가, 부채 증가 |
| 미수수익 (Accrued Revenue) | 발생했지만 아직 수령하지 않은 수익 | 자산 증가, 수익 증가 |
| 선급비용 (Prepaid Expenses) | 미리 지급했지만 아직 소비되지 않은 비용 | 비용 증가, 자산 감소 |
| 선수수익 (Unearned Revenue) | 미리 받았지만 아직 수행하지 않은 수익 | 부채 감소, 수익 증가 |

---

## 주요 수정분개 사례

### 1. 감가상각 (Depreciation) 분개

유형자산 (Property, Plant and Equipment)은 시간이 지남에 따라 가치가 감소한다. 이 감소분을 비용으로 인식하는 것이 감가상각이다. 토지 (Land)는 감가상각 대상이 아니다.

#### 감가상각 방법

**정액법 (Straight-line Method)**:
```
연간 감가상각비 = (취득원가 - 잔존가치) / 내용연수
```

**정률법 (Declining Balance Method)**:
```
연간 감가상각비 = 기초 장부가액 × 상각률
```

#### 예시: 정액법

업무용 차량을 3,000만 원에 구매, 내용연수 5년, 잔존가치 500만 원인 경우:
```
연간 감가상각비 = (30,000,000 - 5,000,000) / 5 = 5,000,000원
```

**수정분개**:
```
(차변) 감가상각비 (Depreciation Expense)        5,000,000
    (대변) 감가상각누계액 (Accumulated Depreciation)    5,000,000
```

감가상각누계액은 자산의 차감 계정 (Contra Account)이다. 자산 자체를 직접 줄이지 않고, 별도의 차감 계정을 사용하여 원래 취득원가 정보를 유지한다.

#### 세법상 감가상각

세법에서는 자산의 종류별로 **법정 내용연수 (Statutory Useful Life)**와 상각 방법을 규정하고 있다:

| 자산 | 내용연수 | 허용 방법 |
|------|---------|---------|
| 건물 | 20~40년 | 정액법 |
| 기계장치 | 4~12년 | 정액법, 정률법 |
| 차량운반구 | 4~6년 | 정액법, 정률법 |
| 비품 | 3~6년 | 정액법, 정률법 |

---

### 2. 미지급비용 (Accrued Expenses) 분개

이미 발생했지만 아직 대금을 지급하지 않은 비용이다. 기말에 인식해야 정확한 손익 계산이 가능하다.

#### 예시: 미지급급여

12월분 급여 4,000만 원이 1월 10일에 지급 예정인 경우, 12월 31일 결산 시:

```
(차변) 급여 (Salaries Expense)             40,000,000
    (대변) 미지급비용 (Accrued Expenses)          40,000,000
```

#### 예시: 미지급이자

은행 차입금 1억 원에 대한 연이자율 5%에서, 10월 1일 차입하여 12월 31일 결산 시 (3개월분 이자):

```
미지급이자 = 100,000,000 × 5% × 3/12 = 1,250,000원

(차변) 이자비용 (Interest Expense)          1,250,000
    (대변) 미지급비용 (Accrued Expenses)           1,250,000
```

---

### 3. 선수수익 (Unearned Revenue) 분개

대금을 미리 받았지만, 아직 서비스를 완전히 제공하지 않은 경우이다. 처음에는 부채 (선수수익)로 기록했다가, 서비스를 제공한 만큼 수익으로 전환한다.

#### 예시: 연간 구독료

11월 1일에 연간 유지보수 서비스 계약 1,200만 원을 선수령한 경우:

**11월 1일 수령 시**:
```
(차변) 현금 (Cash)                         12,000,000
    (대변) 선수수익 (Unearned Revenue)            12,000,000
```

**12월 31일 결산 시** (2개월분 수익 인식):
```
수익 인식액 = 12,000,000 × 2/12 = 2,000,000원

(차변) 선수수익 (Unearned Revenue)          2,000,000
    (대변) 용역매출 (Service Revenue)              2,000,000
```

결산 후 선수수익 잔액: 10,000,000원 (나머지 10개월분은 다음 기에 수익 인식)

---

### 4. 대손충당금 (Allowance for Bad Debts) 분개

매출채권 (Accounts Receivable) 중 회수가 불가능할 것으로 예상되는 금액을 미리 비용으로 인식한다. 이는 **보수주의 원칙 (Conservatism Principle)**에 기반한다.

#### 대손충당금 설정 방법

**매출채권 잔액 비율법 (Percentage of Receivables Method)**:
```
기말 대손충당금 잔액 = 기말 매출채권 잔액 × 대손추정률
대손상각비 = 기말 대손충당금 잔액 - 수정 전 대손충당금 잔액
```

#### 예시

기말 매출채권 잔액 5,000만 원, 대손추정률 5%, 수정 전 대손충당금 잔액 50만 원인 경우:

```
필요 대손충당금 = 50,000,000 × 5% = 2,500,000원
추가 설정액 = 2,500,000 - 500,000 = 2,000,000원

(차변) 대손상각비 (Bad Debt Expense)        2,000,000
    (대변) 대손충당금 (Allowance for Bad Debts)    2,000,000
```

#### 세법상 대손충당금

세법에서는 대손충당금 설정 한도를 규정하고 있다:
- 일반 채권: 채권 잔액의 **1%**와 대손실적률 중 큰 금액
- 금융기관: 별도 기준 적용

---

### 5. 재고자산 (Inventory) 평가

기말 재고자산은 취득원가와 순실현가능가치 (Net Realizable Value; NRV) 중 **낮은 금액 (Lower of Cost or NRV)**으로 평가한다. 이것을 저가법 (Lower of Cost or Market; LCM)이라 한다.

#### 재고자산 평가 방법

| 방법 | 영문 | 설명 |
|------|------|------|
| 선입선출법 | First-In, First-Out (FIFO) | 먼저 매입한 것이 먼저 판매된 것으로 가정 |
| 후입선출법 | Last-In, First-Out (LIFO) | 나중에 매입한 것이 먼저 판매된 것으로 가정 (K-IFRS 불허) |
| 총평균법 | Weighted Average Method | 기간 전체의 평균 단가로 계산 |
| 이동평균법 | Moving Average Method | 매입 시마다 평균 단가를 재계산 |
| 개별법 | Specific Identification | 개별 물품의 실제 원가를 추적 |

#### 예시: 재고자산 평가손실

기말 재고자산의 취득원가 3,500만 원, 순실현가능가치 3,200만 원인 경우:

```
재고자산평가손실 = 35,000,000 - 32,000,000 = 3,000,000원

(차변) 재고자산평가손실 (Inventory Write-down)  3,000,000
    (대변) 재고자산 (Inventory)                        3,000,000
```

---

### 6. 선급비용 (Prepaid Expenses) 조정

미리 지급한 비용 중 기간이 경과하여 비용으로 전환되어야 할 부분을 인식한다.

#### 예시: 보험료

7월 1일에 1년간 화재보험료 2,400만 원을 선납한 경우:

**7월 1일 지급 시**:
```
(차변) 선급비용 (Prepaid Insurance)         24,000,000
    (대변) 현금 (Cash)                            24,000,000
```

**12월 31일 결산 시** (6개월분 비용 인식):
```
비용 인식액 = 24,000,000 × 6/12 = 12,000,000원

(차변) 보험료 (Insurance Expense)           12,000,000
    (대변) 선급비용 (Prepaid Insurance)            12,000,000
```

결산 후 선급비용 잔액: 12,000,000원 (나머지 6개월분은 다음 기에 비용 인식)

## 결산 마감 분개 (Closing Entries)

수정분개가 완료되고 재무제표가 작성되면, 임시 계정 (Temporary Accounts)을 마감한다. 임시 계정이란 해당 기간에만 유효한 수익·비용 계정이다. 영구 계정 (Permanent Accounts)인 자산·부채·자본 계정과 대비된다.

### 마감 분개의 목적

1. **수익·비용 계정의 잔액을 0으로 만든다**: 다음 기간에는 새로운 수익·비용이 기록되어야 하므로
2. **당기순이익을 이익잉여금으로 이체한다**: 손익계산서의 최종 결과를 재무상태표에 반영한다

### 마감 분개의 순서

집합손익 (Income Summary) 계정을 이용하는 방법이 일반적이다:

#### Step 1: 수익 계정 마감

모든 수익 계정의 잔액을 집합손익 계정으로 이체한다.

```
(차변) 상품매출 (Sales)                   450,000,000
(차변) 용역매출 (Service Revenue)           50,000,000
(차변) 이자수익 (Interest Income)            5,000,000
(차변) 임대료수익 (Rental Income)            2,000,000
(차변) 잡이익 (Miscellaneous Income)         1,000,000
    (대변) 집합손익 (Income Summary)              508,000,000
```

#### Step 2: 비용 계정 마감

모든 비용 계정의 잔액을 집합손익 계정으로 이체한다.

```
(차변) 집합손익 (Income Summary)           462,640,000
    (대변) 매출원가 (COGS)                       300,000,000
    (대변) 급여 (Salaries)                        60,000,000
    (대변) 퇴직급여 (Retirement Benefits)           6,000,000
    (대변) 복리후생비 (Employee Benefits)           10,000,000
    (대변) 임차료 (Rent)                           18,000,000
    (대변) 감가상각비 (Depreciation)                12,000,000
    (대변) 기타 판관비                              34,000,000
    (대변) 이자비용 (Interest Expense)               9,000,000
    (대변) 기타 영업외비용                            3,000,000
    (대변) 법인세비용 (Income Tax)                  10,640,000
```

#### Step 3: 집합손익 마감 → 이익잉여금으로 이체

```
집합손익 잔액 = 508,000,000 (대변) - 462,640,000 (차변) = 45,360,000 (대변, 이익)

(차변) 집합손익 (Income Summary)            45,360,000
    (대변) 이익잉여금 (Retained Earnings)         45,360,000
```

만약 당기순손실이 발생했다면 반대 분개가 된다:
```
(차변) 이익잉여금 (Retained Earnings)       xxx
    (대변) 집합손익 (Income Summary)               xxx
```

#### Step 4: 배당금 (Dividends) 마감 (해당 시)

배당금을 선언한 경우, 배당금 계정도 마감한다:
```
(차변) 이익잉여금 (Retained Earnings)       xxx
    (대변) 배당금 (Dividends)                      xxx
```

## 이월시산표 (Post-closing Trial Balance)

결산 마감 분개를 모두 전기한 후 작성하는 시산표이다. 이 시산표에는 **영구 계정 (Permanent Accounts)**만 남아 있다.

### 이월시산표의 특징

- **수익·비용 계정이 없다**: 모든 임시 계정이 마감되어 잔액이 0이다
- **자산·부채·자본 계정만 존재**: 이것이 다음 기의 기초 잔액이 된다
- **차변 합계 = 대변 합계**: 복식부기의 기본 원리가 유지된다

### 이월시산표 예시

```
============================================================
            (주)한빛상사 이월시산표
            2025년 12월 31일 현재
                                            (단위: 천원)
============================================================
계정과목                      차변          대변
------------------------------------------------------------
현금및현금성자산              30,000
단기금융상품                  20,000
매출채권                      50,000
대손충당금                                   2,500
재고자산                      35,000
선급비용                       7,500
미수수익                       5,000
장기금융상품                  20,000
장기투자증권                  10,000
```

## 개발자가 알아야 할 것 (What Developers Need to Know)

### 시스템 설계에 미치는 영향

- **결산 상태 관리**: 회계기간별로 "미마감", "수정분개 진행중", "마감완료" 등의 상태 관리가 필요하다. 마감된 기간에는 분개 입력을 차단해야 한다.
- **수정분개 자동화**: 감가상각, 선급비용 소멸, 선수수익 인식 등 정기적인 수정분개는 시스템에서 자동 생성하도록 설계할 수 있다. 스케줄링 기능이 필요하다.
- **마감 취소 (Reopen) 기능**: 결산 확정 후에도 오류가 발견될 수 있으므로, 권한이 있는 사용자가 마감을 해제하고 수정할 수 있는 기능이 필요하다. 감사 추적 (Audit Trail)은 필수이다.
- **결산 마감 분개 자동 생성**: 수익·비용 계정을 집합손익으로 마감하는 분개는 시스템이 자동으로 생성해야 한다. 계정 분류 코드를 기반으로 임시 계정과 영구 계정을 구분한다.

### 데이터 모델링 포인트

- **회계기간 테이블**: 시작일, 종료일, 상태 (Open/Closed), 마감일시, 마감자 정보를 관리한다
- **수정분개 유형 코드**: 일반 분개와 수정분개, 결산 마감 분개를 구분하는 유형 코드가 필요하다
- **감가상각 마스터**: 자산별 취득일, 취득원가, 내용연수, 잔존가치, 상각방법, 누적상각액을 관리한다
- **결산 일정 관리**: 결산 체크리스트의 각 항목별 담당자, 완료 여부, 완료일을 추적하는 워크플로우가 유용하다
- **전기 이월 처리**: 이월시산표의 각 계정 잔액을 다음 기 기초 잔액으로 자동 이월하는 로직이 필요하다

### ERP 및 회계 프로그램 연동 시 참고 사항

- **더존 Smart A**: 결산 자동화 기능이 있으며, 감가상각비 자동 계산, 결산 마감 분개 자동 생성을 지원한다. API 연동 시 결산 상태를 조회·변경할 수 있다.
- **회계기간 잠금 (Period Lock)**: 마감된 회계기간에 대한 분개 입력을 시스템적으로 차단하는 것이 가장 중요한 내부통제 기능이다
- **감사 추적 (Audit Trail)**: 수정분개와 결산 분개는 누가, 언제, 왜 작성했는지 기록해야 한다. 외부 감사 시 필수 확인 사항이다
- **세무조정 연계**: 결산이 완료되면 세무조정 모듈로 데이터를 전달하여 법인세 신고를 준비한다. 회계상 이익과 세무상 과세소득의 차이를 관리하는 별도 로직이 필요하다

## 용어 사전 (Glossary)

| 한글 | 영문 | 설명 |
|------|------|------|
| 결산 | Closing | 회계기간 종료 시 재무제표를 확정하는 일련의 절차 |
| 수정분개 | Adjusting Entries | 기말에 발생주의에 맞게 수익·비용을 조정하는 분개 |
| 감가상각 | Depreciation | 유형자산의 취득원가를 내용연수에 걸쳐 비용화하는 과정 |
| 정액법 | Straight-line Method | 매년 동일 금액을 감가상각하는 방법 |
| 정률법 | Declining Balance Method | 장부가액에 일정 비율을 적용하여 감가상각하는 방법 |
| 미지급비용 | Accrued Expenses | 발생했지만 아직 지급하지 않은 비용 |
| 선수수익 | Unearned Revenue | 미리 받았지만 아직 서비스를 제공하지 않은 수익 |
| 대손충당금 | Allowance for Bad Debts | 매출채권 중 회수 불능 예상액을 미리 설정한 금액 |
| 집합손익 | Income Summary | 수익·비용 계정을 마감할 때 사용하는 임시 집합 계정 |
| 임시 계정 | Temporary Accounts | 해당 기간에만 유효한 계정 (수익, 비용, 배당금) |
| 영구 계정 | Permanent Accounts | 기간에 관계없이 이월되는 계정 (자산, 부채, 자본) |
| 이월시산표 | Post-closing Trial Balance | 결산 마감 후 영구 계정만으로 작성한 시산표 |
| 재고자산 평가 | Inventory Valuation | 기말 재고자산의 가치를 결정하는 과정 |
| 저가법 | Lower of Cost or Market | 취득원가와 시가 중 낮은 금액으로 평가하는 방법 |
| 발생주의 | Accrual Basis | 현금 수수와 관계없이 경제적 사건 발생 시 인식하는 원칙 |
