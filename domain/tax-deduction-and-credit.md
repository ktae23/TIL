## 1. 종합소득세 계산 구조

종합소득세는 개인이 1년간 벌어들인 모든 소득을 합산하여 신고·납부하는 세금이다. 소득공제와 세액공제는 이 계산 파이프라인의 **서로 다른 단계**에서 적용된다.

```
총수입금액
  │
  │  (-) 필요경비
  ▼
소득금액
  │
  │  (-) ★ 소득공제 ← 과세표준을 줄여준다
  ▼
과세표준
  │
  │  (×) 누진세율 (6%~45%)
  ▼
산출세액
  │
  │  (-) ★ 세액공제 ← 세금 자체를 줄여준다
  ▼
결정세액
  │
  │  (-) 기납부세액 (원천징수 등)
  ▼
납부할 세액 (음수면 환급)
```

> **핵심:** 소득공제는 **과세표준 산정 전**, 세액공제는 **산출세액 산정 후**에 적용된다.

## 2. 소득공제란

**소득공제(Income Deduction)**는 과세표준을 계산하기 전에 소득금액에서 차감하는 금액이다. 과세표준이 낮아지면 적용되는 **세율 구간 자체가 내려갈 수 있어** 절세 효과가 크다.

### 소득공제의 효과

소득공제 100만원의 실질 절세 효과는 **적용 세율에 따라 달라진다**.

| 적용 세율 구간 | 소득공제 100만원의 절세 효과 |
|:---:|:---:|
| 6% | 6만원 |
| 15% | 15만원 |
| 24% | 24만원 |
| 35% | 35만원 |
| 38% | 38만원 |
| 45% | 45만원 |

> 소득이 높을수록(세율이 높을수록) 동일한 소득공제 금액의 절세 효과가 커진다.

### 주요 소득공제 항목

| 공제 항목 | 공제 금액 | 대상/조건 |
|-----------|----------|-----------|
| 기본공제 (본인) | 150만원 | 모든 납세자 |
| 기본공제 (배우자) | 150만원 | 연소득 100만원 이하 배우자 |
| 기본공제 (부양가족) | 1인당 150만원 | 60세 이상 부모, 20세 이하 자녀 등 |
| 국민연금 보험료 | 납입액 전액 | 본인 부담분 |
| 건강보험료 | 납입액 전액 | 본인 부담분 |
| 주택담보대출 이자 | 300~1,800만원 | 무주택·1주택 세대주 |
| 개인연금저축 | 납입액의 40% (72만원 한도) | 2000년 이전 가입자 |
| 소기업·소상공인 공제 (노란우산) | 납입액 (200~500만원 한도) | 사업소득 기준 차등 |

## 3. 세액공제란

**세액공제(Tax Credit)**는 산출세액에서 직접 차감하는 금액이다. 세율과 무관하게 **공제 금액만큼 세금이 정확히 줄어든다**.

### 세액공제의 효과

세액공제 100만원은 소득 수준과 관계없이 **항상 100만원의 절세 효과**를 준다.

| 적용 세율 구간 | 세액공제 100만원의 절세 효과 |
|:---:|:---:|
| 6% | **100만원** |
| 15% | **100만원** |
| 24% | **100만원** |
| 35% | **100만원** |
| 45% | **100만원** |

> 세율에 무관하게 일정한 절세 효과 → 저소득자에게 상대적으로 유리

### 주요 세액공제 항목

| 공제 항목 | 공제 금액/방식 | 대상/조건 |
|-----------|:---:|-----------|
| 자녀세액공제 | 1명 15만원, 2명 35만원, 3명~ +30만원 | 7세 이상 자녀 |
| 출산·입양세액공제 | 첫째 30만원, 둘째 50만원, 셋째~ 70만원 | 해당 연도 출산·입양 |
| 연금계좌세액공제 | 납입액의 12~15% | IRP·연금저축 (한도 900만원) |
| 보험료세액공제 | 납입액의 12~15% | 보장성 보험 (한도 100만원) |
| 의료비세액공제 | 초과분의 15% | 총급여 3% 초과 의료비 |
| 교육비세액공제 | 납입액의 15% | 본인 전액, 자녀 한도 있음 |
| 기부금세액공제 | 기부액의 15~30% | 법정·지정 기부금 |
| 기장세액공제 | 산출세액의 20% (100만원 한도) | 간편장부 대상자가 복식부기 시 |
| 전자신고세액공제 | 2만원 | 전자(홈택스) 신고 시 |
| 표준세액공제 | 7만원 | 항목별 공제 미적용 시 |

## 4. 소득공제 vs 세액공제 비교

| 비교 항목 | 소득공제 | 세액공제 |
|-----------|---------|---------|
| **적용 시점** | 과세표준 산정 **전** | 산출세액 산정 **후** |
| **차감 대상** | 소득금액 | 산출세액(세금) |
| **절세 효과** | 적용 세율에 비례 (가변적) | 공제 금액 그대로 (고정적) |
| **고소득자 유리?** | 세율 높을수록 효과 큼 | 소득 무관, 동일 효과 |
| **저소득자 유리?** | 효과 작음 | 상대적으로 유리 |
| **영문 용어** | Income Deduction | Tax Credit |
| **코드 매핑** | `incomeDeduction` | `taxCredit` |
| **정책 방향** | 점차 축소 추세 | 점차 확대 추세 |

### 왜 소득공제에서 세액공제로 전환되는가?

정부는 **조세 형평성**을 위해 소득공제를 세액공제로 전환하는 추세다.

```
소득공제 방식의 문제:
  고소득자 (세율 35%) → 100만원 공제 시 35만원 절세
  저소득자 (세율  6%) → 100만원 공제 시  6만원 절세
  → 같은 공제인데 고소득자가 약 6배 더 혜택

세액공제 방식으로 전환:
  고소득자 → 100만원 세액공제 시 100만원 절세
  저소득자 → 100만원 세액공제 시 100만원 절세
  → 동일한 혜택, 형평성 확보
```

> 2014년 연말정산 개편 이후 의료비·교육비·보험료·기부금 등이 소득공제에서 세액공제로 전환되었다.

## 5. 계산 예시로 보는 차이

### 시나리오: 프리랜서 연소득 5,000만원

```
[기본 정보]
  총수입금액:  50,000,000원
  필요경비:   20,000,000원
  소득금액:   30,000,000원

[Case A] 소득공제 300만원 적용
  소득금액:       30,000,000원
  (-) 소득공제:    -3,000,000원  ← ★
  과세표준:       27,000,000원
  산출세액:  27,000,000 × 15% - 1,260,000 = 2,790,000원

[Case B] 세액공제 300만원 적용
  소득금액:       30,000,000원
  (-) 소득공제:            0원
  과세표준:       30,000,000원
  산출세액:  30,000,000 × 15% - 1,260,000 = 3,240,000원
  (-) 세액공제:   -3,000,000원  ← ★
  결정세액:          240,000원
```

| 구분 | Case A (소득공제) | Case B (세액공제) |
|:---:|:---:|:---:|
| 공제 금액 | 300만원 | 300만원 |
| 산출세액 | 279만원 | 324만원 |
| 세액공제 후 | 279만원 | **24만원** |
| **실질 절세액** | **45만원** (300만 × 15%) | **300만원** (전액) |

> 같은 300만원이라도 소득공제는 45만원, 세액공제는 300만원의 절세 효과 → **세액공제가 약 6.7배 유리**
