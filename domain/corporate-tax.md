## 1. 법인의 종류와 특성

법인(Corporation)은 법률에 의해 권리와 의무의 주체로 인정되는 조직체다. 자연인(개인)과 달리 법적으로 별도의 인격을 갖는다.

### 법인의 종류

| 분류 기준 | 종류 | 설명 |
|-----------|------|------|
| **설립 목적** | 영리법인 (For-profit Corporation) | 이윤 추구를 목적으로 설립 (주식회사, 유한회사 등) |
| | 비영리법인 (Non-profit Corporation) | 학술, 종교, 자선 등 비영리 목적 |
| **설립 근거** | 상법상 법인 | 상법에 근거하여 설립 |
| | 특별법에 의한 법인 | 특별법에 근거 (공기업, 특수법인 등) |
| **내국/외국** | 내국법인 (Domestic Corporation) | 본점·주사무소가 국내에 있는 법인 |
| | 외국법인 (Foreign Corporation) | 본점·주사무소가 해외에 있는 법인 |

### 법인 형태별 특성

| 구분 | 주식회사 (Corporation) | 유한회사 (LLC) | 유한책임회사 (LLP) |
|------|----------------------|---------------|-------------------|
| 출자자 명칭 | 주주 (Shareholder) | 사원 (Member) | 사원 (Member) |
| 최소 출자자 | 1인 이상 | 1인 이상 | 2인 이상 |
| 책임 범위 | 유한책임 (출자액 한도) | 유한책임 | 유한책임 |
| 지분 양도 | 자유 (상장 시) | 사원 동의 필요 | 사원 동의 필요 |
| 외부감사 | 일정 규모 이상 의무 | 일정 규모 이상 의무 | 의무 아님 |
| 이사회 | 필수 | 선택 | 선택 |

> **실무**: 한국의 중소 스타트업은 대부분 **주식회사** 형태로 설립한다. 투자 유치, 스톡옵션 발행, 상장 등에 유리하기 때문이다.

### 법인의 세무적 특성

법인은 개인과 달리 법적으로 독립된 과세 주체다. 따라서:

- **법인 자체가 세금을 납부**한다 (법인세)
- 법인의 이익을 주주에게 배당하면 **주주에게도 배당소득세**가 부과된다 (이중과세 문제)
- 법인 대표이사의 급여는 법인의 **비용(손금)**으로 인정된다 (개인사업자와 핵심 차이)
- 법인은 **복식부기 의무**가 있다

```
┌────────────────────────────────────────────────────────┐
│              법인의 소득 흐름과 과세                      │
├────────────────────────────────────────────────────────┤
│                                                        │
│  법인의 매출 (Revenue)                                  │
│       │                                                │
│       │  (-) 비용 (Expenses) ← 대표이사 급여 포함        │
│       ▼                                                │
│  법인의 이익 (Profit) ──► 법인세 (Corporate Tax) 납부     │
│       │                                                │
│       │  배당 결정                                      │
│       ▼                                                │
│  배당금 (Dividend) ──► 주주에게 배당소득세 부과           │
│                        (이중과세)                        │
│                                                        │
└────────────────────────────────────────────────────────┘
```

## 2. 법인세 개요

법인세(Corporate Tax)는 법인이 각 사업연도에 벌어들인 소득에 대해 부과되는 세금이다. 개인에게 종합소득세가 있듯이, 법인에게는 법인세가 있다.

### 법인세의 과세 대상

| 과세 대상 | 내용 | 적용 |
|-----------|------|------|
| 각 사업연도 소득 (Income of Each Business Year) | 사업연도 동안 벌어들인 순소득 | 가장 일반적 |
| 토지 등 양도소득 (Capital Gains on Land) | 토지·건물 양도 시 추가 과세 | 특정 조건 |
| 미환류소득 (Undistributed Income) | 투자·배당·임금 미환류분에 과세 | 대기업 적용 |
| 청산소득 (Liquidation Income) | 법인 청산 시 잔여재산 가액 | 해산 시 |

### 사업연도 (Business Year)

법인세는 법인의 **사업연도**(Business Year) 단위로 과세된다. 사업연도는 법인이 정관(Articles of Incorporation)으로 정할 수 있다.

- 대부분의 법인: **1월 1일 ~ 12월 31일** (역년 기준)
- 일부 법인: 4월 1일 ~ 3월 31일 등 임의 설정 가능
- 사업연도는 1년을 초과할 수 없음

## 3. 법인세 과세표준 계산

법인세의 과세표준(Tax Base) 계산은 **기업회계이익에서 출발**하여 **세무조정**을 거친다는 점이 핵심이다.

### 과세표준 계산의 전체 흐름

```
기업회계이익 (Accounting Profit)     ← 결산서(재무제표) 상의 당기순이익
      │
      │  (+) 익금산입 (Addition to Revenue)
      │  (-) 익금불산입 (Exclusion from Revenue)
      │  (+) 손금불산입 (Disallowed Expenses)
      │  (-) 손금산입 (Addition to Expenses)
      ▼
각 사업연도 소득 (Taxable Income before deductions)
      │
      │  (-) 이월결손금 공제 (Loss Carryforward)
      │  (-) 비과세소득 (Non-taxable Income)
      │  (-) 소득공제 (Income Deductions)
      ▼
과세표준 (Tax Base)
      │
      │  (×) 세율 (Tax Rate)
      ▼
산출세액 (Calculated Tax)
      │
      │  (-) 세액공제 (Tax Credits)
      │  (-) 세액감면 (Tax Reductions)
      ▼
결정세액 (Determined Tax)
      │
      │  (+) 가산세 (Penalties)
      ▼
총결정세액 (Total Determined Tax)
      │
      │  (-) 기납부세액 (Prepaid Tax)
      │      ├ 중간예납세액
      │      ├ 원천징수세액
      │      └ 수시부과세액
      ▼
납부할 세액 (Tax Payable) or 환급세액 (Tax Refund)
```

### 핵심 개념: 기업회계 vs 세무회계

**기업회계(Financial Accounting)**는 기업회계기준(K-GAAP 또는 K-IFRS)에 따라 재무제표를 작성하는 것이고, **세무회계(Tax Accounting)**는 세법에 따라 과세소득을 계산하는 것이다.

두 회계 기준이 항상 일치하지는 않는다. 이 차이를 조정하는 것이 **세무조정(Tax Adjustment)**이다.

```
┌──────────────────────────┐   세무조정   ┌──────────────────────────┐
│     기업회계 (K-GAAP)     │ ──────────► │      세무회계 (Tax)       │
│     당기순이익 (Net Income)│             │   각 사업연도 소득        │
│                          │   차이 발생!  │   (Taxable Income)       │
│ - 보수주의 원칙 적용       │             │ - 세법 규정 엄격 적용     │
│ - 추정 비용 인정           │             │ - 일부 비용 불인정        │
│ - 경영 판단 반영           │             │ - 과세 형평성 추구        │
└──────────────────────────┘             └──────────────────────────┘
```

## 4. 세무조정의 구조

세무조정(Tax Adjustment)은 기업회계이익과 세무상 과세소득의 차이를 조정하는 과정이다. 법인세에서 가장 핵심적인 부분이다.

### 세무조정의 4가지 유형

| 유형 | 영문 | 의미 | 효과 |
|------|------|------|------|
| 익금산입 (益金算入) | Addition to Revenue | 회계상 수익이 아니지만 세법상 익금(Revenue)으로 봄 | 과세소득 증가 |
| 익금불산입 (益金不算入) | Exclusion from Revenue | 회계상 수익이지만 세법상 익금에서 제외 | 과세소득 감소 |
| 손금불산입 (損金不算入) | Disallowed Expenses | 회계상 비용이지만 세법상 손금(Expense)으로 불인정 | 과세소득 증가 |
| 손금산입 (損金算入) | Addition to Expenses | 회계상 비용이 아니지만 세법상 손금으로 인정 | 과세소득 감소 |

### 세무조정 방향 정리

```
과세소득 증가 (세금 ↑)          과세소득 감소 (세금 ↓)
┌─────────────────┐           ┌─────────────────┐
│  익금산입         │           │  익금불산입       │
│  (수익 추가)      │           │  (수익 제외)      │
├─────────────────┤           ├─────────────────┤
│  손금불산입       │           │  손금산입         │
│  (비용 불인정)    │           │  (비용 추가)      │
└─────────────────┘           └─────────────────┘
```

### 세무조정 예시

#### 익금산입 (Addition to Revenue)

- 자산의 무상 수입 (Gratuitous Receipt of Assets)
- 채무 면제이익 (Debt Forgiveness Income)
- 자산의 평가증 (Asset Revaluation Gain)

#### 익금불산입 (Exclusion from Revenue)

- 법인세 환급금에 대한 이자 (Interest on Tax Refund)
- 내국법인에서 받은 수입배당금 일부 (Dividend Income Exclusion)
- 자기주식 처분이익 (Gain on Disposal of Treasury Stock) — 자본거래

#### 손금불산입 (Disallowed Expenses)

- 접대비 한도 초과액 (Excess Entertainment Expenses)
- 감가상각비 상각 한도 초과액 (Excess Depreciation)
- 벌금·과료 (Fines & Penalties)
- 법인세·주민세 (Corporate Tax, Resident Tax)
- 업무 무관 지출 (Non-business Expenses)
- 부당행위계산부인 관련 비용

#### 손금산입 (Addition to Expenses)

- 기업회계상 미계상 감가상각비 중 세법상 인정되는 부분 (세법상 시부인 조정)
- 일부 준비금·충당금 중 세법상 특별히 인정하는 것

### 세무조정 계산 예시

```
기업회계 당기순이익:        100,000,000원

세무조정 내역:
  (+) 익금산입
      채무면제이익              5,000,000원
  (-) 익금불산입
      수입배당금 익금불산입     (3,000,000원)
  (+) 손금불산입
      접대비 한도초과            2,000,000원
      감가상각 한도초과          4,000,000원
      법인세 납부액             10,000,000원
      벌금                      1,000,000원
  (-) 손금산입
      (해당 없음)                       0원

각 사업연도 소득:
  = 100,000,000 + 5,000,000 - 3,000,000 + 17,000,000 - 0
  = 119,000,000원

  (-) 이월결손금 공제                     0원
  (-) 비과세소득                          0원

과세표준:                   119,000,000원
```

## 5. 법인세 세율

법인세도 종합소득세와 마찬가지로 누진세율(Progressive Tax Rate)을 적용하지만, 세율 구간이 다르다.

### 법인세 세율표 (일반 영리법인)

| 과세표준 (Tax Base) | 세율 (Rate) | 누진공제 (Progressive Deduction) |
|---------------------|-------------|-------------------------------|
| 2억 원 이하 | 9% | — |
| 2억 원 초과 ~ 200억 원 이하 | 19% | 2,000만 원 |
| 200억 원 초과 ~ 3,000억 원 이하 | 21% | 4억 2,000만 원 |
| 3,000억 원 초과 | 24% | 94억 2,000만 원 |

> **참고**: 지방소득세(Local Income Tax)가 법인세의 10%로 별도 부과된다. 따라서 실효세율은 표면 세율의 1.1배다.

### 계산 예시

```
과세표준: 119,000,000원 (1억 1,900만 원)

산출세액 = 119,000,000 × 9% = 10,710,000원
(2억 원 이하이므로 9% 단일 적용)

지방소득세 = 10,710,000 × 10% = 1,071,000원

총 세부담 = 10,710,000 + 1,071,000 = 11,781,000원
```

```
과세표준: 500,000,000원 (5억 원)

산출세액 = 500,000,000 × 19% - 20,000,000 = 75,000,000원

지방소득세 = 75,000,000 × 10% = 7,500,000원

총 세부담 = 75,000,000 + 7,500,000 = 82,500,000원
```

## 6. 법인세 신고 절차

### 신고 기한

법인세는 **각 사업연도 종료일이 속하는 달의 말일부터 3개월 이내**에 신고·납부해야 한다.

| 사업연도 | 종료일 | 신고 기한 |
|----------|--------|-----------|
| 1월~12월 | 12월 31일 | 3월 31일 |
| 4월~3월 | 3월 31일 | 6월 30일 |
| 7월~6월 | 6월 30일 | 9월 30일 |

> **성실신고확인 대상 법인**: 신고 기한이 1개월 연장된다 (12월 결산 법인의 경우 4월 30일).

### 신고 시 제출 서류

1. **법인세 과세표준 및 세액신고서** (Corporate Tax Return)
2. **재무상태표** (Statement of Financial Position / Balance Sheet)
3. **포괄손익계산서** (Statement of Comprehensive Income)
4. **이익잉여금처분계산서** (Statement of Appropriation of Retained Earnings)
5. **세무조정계산서** (Tax Adjustment Statement)
6. **부속명세서** (Supplementary Schedules)

### 전자신고

- 대부분의 법인은 **홈택스(Hometax)**를 통해 전자신고
- 세무대리인(세무사, 회계사)이 **위택스** 등을 통해 대리 신고 가능
- 전자신고 시 세액공제 2만 원 적용

## 7. 중간예납

중간예납(Interim Payment)은 법인세 부담을 분산하기 위해 사업연도 중간에 미리 세금의 일부를 납부하는 제도다.

### 중간예납 시기

- **사업연도 개시일부터 6개월이 되는 날부터 2개월 이내** 신고·납부
- 12월 결산 법인: 8월 31일까지 (1~6월분에 대해)

### 중간예납 계산 방법 (택일)

| 방법 | 계산식 | 적합한 경우 |
|------|--------|------------|
| 직전 사업연도 기준 | 직전 사업연도 법인세액 × 6/12 | 전년과 실적이 비슷할 때 |
| 당해 사업연도 가결산 기준 | 중간 기간(6개월) 실적으로 가결산 | 전년보다 실적이 크게 줄었을 때 |

### 중간예납 면제

다음의 경우 중간예납 의무가 면제된다:

- 해당 사업연도에 신설된 법인
- 중간예납세액이 50만 원 미만인 경우
- 휴업 중인 법인
- 청산 중인 법인

## 8. 법인세 주요 세무조정 사례

실무에서 자주 발생하는 세무조정 항목을 상세히 살펴본다.

### 8.1 접대비 한도 (Entertainment Expense Limit)

접대비(Entertainment Expense)는 사업 관련 거래처 접대에 지출한 비용이다. 세법은 남용을 방지하기 위해 한도를 설정한다.

#### 접대비 한도액 계산

```
접대비 한도액 = 기본 한도 + 수입금액별 추가 한도

기본 한도:
  - 일반법인: 3,600만 원 (중소기업: 3,600만 원)

수입금액별 추가 한도:
  ┌───────────────────────────┬──────────┐
  │ 수입금액 구간              │ 적용률    │
  ├───────────────────────────┼──────────┤
  │ 100억 원 이하              │ 0.3%     │
  │ 100억 원 초과 ~ 500억 원   │ 0.2%     │
  │ 500억 원 초과              │ 0.03%    │
  └───────────────────────────┴──────────┘
```

#### 세무조정

```
회계상 접대비 지출: 50,000,000원
접대비 한도액:      42,000,000원 (기본 3,600만 원 + 추가 600만 원)
한도 초과액:         8,000,000원

→ 손금불산입 8,000,000원 (과세소득 증가)
```

#### 접대비 증빙 요건

- 건당 3만 원 초과 시 적격증빙(세금계산서, 신용카드, 현금영수증 등) 필수
- 적격증빙 미수취 시 전액 손금불산입
- 경조금은 건당 20만 원까지 적격증빙 없이 인정

### 8.2 감가상각 한도 (Depreciation Limit)

세법은 감가상각(Depreciation) 방법과 내용연수에 대해 별도 규정을 두고 있다.

#### 세법상 감가상각 원칙

| 항목 | 세법 규정 |
|------|-----------|
| 상각 방법 | 정액법(Straight-line), 정률법(Declining Balance) 중 신고한 방법 |
| 내용연수 | 세법상 기준내용연수 ± 25% 범위 |
| 상각 범위 | 세법상 한도액까지만 손금 인정 |

#### 세무조정 사례

```
회계상 감가상각비:  20,000,000원
세법상 상각 한도:   15,000,000원
한도 초과액:         5,000,000원

→ 손금불산입 5,000,000원 (유보 — 향후 역전 가능)
```

> **유보(Reserve)**: 감가상각비 한도 초과는 영구적으로 불인정되는 것이 아니라, 향후 세법상 상각액이 회계상 상각액보다 클 때 역전된다. 이를 **유보** 항목이라 한다.

### 8.3 대손금 (Bad Debt Expense)

대손금(Bad Debt Expense)은 회수 불능 채권을 비용으로 처리하는 것이다.

#### 세법상 대손금 인정 요건

- 채무자의 파산, 강제집행, 사망, 행방불명
- 소멸시효 완성
- 회수 불능이 객관적으로 입증된 경우
- 부도 발생 후 6개월 이상 경과

#### 세법상 대손충당금 (Allowance for Bad Debts)

```
대손충당금 한도 = MAX(채권 잔액 × 1%, 대손실적률 × 채권 잔액)
```

- 회계상 더 많이 설정한 경우 → 초과분 손금불산입
- 회계상 적게 설정한 경우 → 세법상 한도까지 손금산입 가능

### 8.4 업무용승용차 관련 비용 (Business Vehicle Expenses)

업무용승용차(Business Vehicle)에 대한 세법상 규정은 매우 엄격하다.

#### 주요 규정

| 항목 | 한도 | 비고 |
|------|------|------|
| 감가상각비 | 연 800만 원 한도 | 리스료 포함 |
| 처분손실 | 연 800만 원 한도 | 초과분은 이월 |
| 총 비용 한도 | 연 1,500만 원 | 업무용 사용 비율 적용 |
| 운행일지 | 작성 필수 (1,500만 원 초과 시) | 미작성 시 50%만 인정 |

#### 업무용 사용 비율

```
업무용 사용 비율 = 업무용 운행거리 / 총 운행거리

  비용 인정액 = 관련 비용 × 업무용 사용 비율
```

- 운행일지를 작성하지 않으면 비용의 **50%만 업무용**으로 인정
- 총 비용(감가상각비 + 유류비 + 보험료 + 수선비 + 통행료 등)에 적용

#### 세무조정 예시

```
업무용승용차 관련 총비용: 25,000,000원
업무사용 비율: 70% (운행일지 기반)
업무용 비용: 25,000,000 × 70% = 17,500,000원

한도 적용:
  감가상각비 부분: 10,000,000원 → 한도 8,000,000원 → 초과 2,000,000원
  기타 비용: 7,500,000원

손금불산입:
  개인사용분: 7,500,000원 (30%)
  감가상각 한도초과: 2,000,000원
  합계: 9,500,000원
```

## 9. 법인세 vs 종합소득세 비교

개인사업자와 법인사업자의 세금 구조는 근본적으로 다르다.

### 핵심 비교표

| 비교 항목 | 개인사업자 (종합소득세) | 법인사업자 (법인세) |
|-----------|----------------------|-------------------|
| 세금 명칭 | 종합소득세 (Comprehensive Income Tax) | 법인세 (Corporate Tax) |
| 납세 주체 | 개인 (자연인) | 법인 (법적 인격체) |
| 최고 세율 | 45% (+지방소득세 4.5%) | 24% (+지방소득세 2.4%) |
| 대표자 급여 | 비용 불인정 (필요경비 X) | 비용 인정 (손금 처리) |
| 이익 사용 | 사업주가 자유롭게 사용 | 배당 절차 필요 (배당소득세 부과) |
| 결손금 이월 | 15년 이월공제 | 15년 이월공제 |
| 장부 의무 | 규모에 따라 간편/복식 | 복식부기 의무 |
| 세무조정 | 없음 (필요경비 인정/불인정) | 세무조정 필수 |
| 신고 시기 | 5월 (확정신고) | 사업연도 종료 후 3개월 |
| 추계신고 | 가능 (경비율 적용) | 불가능 |
| 4대 보험 | 지역가입자 | 직장가입자 (회사 부담분 비용) |

### 세 부담 비교 (동일 소득 기준)

```
연간 이익: 100,000,000원 (1억 원) 가정

[개인사업자 — 종합소득세]
  소득금액:      100,000,000원
  소득공제:       (5,000,000원) 가정
  과세표준:       95,000,000원
  산출세액:       95,000,000 × 35% - 15,440,000 = 17,810,000원
  지방소득세:     1,781,000원
  총 세부담:      19,591,000원 (실효세율 약 19.6%)

[법인사업자 — 법인세]
  대표자 급여:    (50,000,000원) ← 법인 비용 처리
  법인 과세소득:   50,000,000원
  법인세:          50,000,000 × 9% = 4,500,000원
  지방소득세:      450,000원
  법인 세부담:     4,950,000원

  대표자 근로소득세 (급여 5천만 원 기준):
  과세표준 약:     40,000,000원 (근로소득공제 등 적용 후)
  산출세액:        40,000,000 × 15% - 1,260,000 = 4,740,000원
  지방소득세:      474,000원
  근로소득세:      5,214,000원

  배당 안 하는 경우 총 세부담: 4,950,000 + 5,214,000 = 10,164,000원
  (실효세율 약 10.2%)

  → 법인이 약 940만 원 절세 효과
```

> **주의**: 위 예시는 단순 비교이며, 실제로는 배당 시 추가 과세, 4대 보험 부담, 법인 설립·유지 비용 등을 종합적으로 고려해야 한다.

## 10. 법인 전환 시 고려사항

개인사업자에서 법인으로 전환하는 것은 단순히 세금 절감만의 문제가 아니라, 사업의 성장 단계와 향후 계획을 종합적으로 고려해야 한다.

### 법인 전환이 유리한 경우

| 기준 | 내용 |
|------|------|
| 소득 규모 | 연 소득 5,000만 원 이상 시 법인이 유리해지기 시작 |
| 사업 확장 | 외부 투자 유치, 파트너십 필요 시 |
| 신용도 | 법인이 대외 신뢰도·거래 유리 |
| 대표자 급여 | 법인에서 대표자 급여를 비용 처리 가능 |
| 리스크 관리 | 유한책임으로 개인재산 보호 |

### 법인 전환 시 세무 이슈

```
┌─────────────────────────────────────────────────────────┐
│              법인 전환 방법과 특징                        │
├──────────────┬──────────────────────────────────────────┤
│ 전환 방법     │ 특징                                     │
├──────────────┼──────────────────────────────────────────┤
│ 현물출자      │ 개인사업 자산·부채를 법인에 현물 출자      │
│ (In-kind      │ 양도소득세 이월과세 특례 적용 가능         │
│  Contribution)│ 사업의 포괄적 양수도                      │
├──────────────┼──────────────────────────────────────────┤
│ 사업양수도    │ 개인사업의 자산·부채를 법인에 매각          │
│ (Business     │ 양도소득세 과세 (부동산 등)               │
│  Transfer)    │ 부가가치세 면제 (포괄적 양수도 시)         │
├──────────────┼──────────────────────────────────────────┤
│ 신규 법인     │ 새 법인 설립 후 개인사업 폐업              │
│ 설립+폐업     │ 자산 이전 시 양도소득세 발생 가능          │
│               │ 가장 단순하지만 세무상 불리할 수 있음       │
└──────────────┴──────────────────────────────────────────┘
```

### 법인 전환 전 체크리스트

1. **세금 시뮬레이션**: 개인 vs 법인 세 부담 비교 (배당 포함)
2. **4대 보험 부담**: 법인 대표자는 직장가입자로 전환 (회사 부담분 발생)
3. **법인 설립 비용**: 등기비용, 법무사 수수료, 공과금
4. **법인 유지 비용**: 세무 기장료 증가, 외부감사 비용 (일정 규모 이상), 법인 등기 관련 비용
5. **배당 이중과세**: 법인에 남긴 이익을 배당하면 배당소득세 추가 과세
6. **퇴직금 중간정산**: 전환 시 기존 직원 퇴직금 처리 문제
7. **인허가 승계**: 기존 인허가의 법인 승계 가능 여부 확인
8. **부동산 이전**: 부동산이 있는 경우 취득세·양도소득세 발생

## 개발자가 알아야 할 것 (What Developers Need to Know)

### 시스템 설계에 미치는 영향

1. **세무조정 엔진**: 법인세 시스템의 핵심은 세무조정이다. 기업회계 데이터를 입력받아 익금산입/익금불산입/손금불산입/손금산입 4가지 조정을 수행하는 엔진이 필요하다. 각 세무조정 항목은 규칙 기반(Rule-based)으로 관리하며, 세법 개정 시 규칙만 업데이트하면 되도록 설계해야 한다.

2. **사업연도 관리**: 법인의 사업연도가 반드시 1~12월이 아닐 수 있다. 시스템은 임의의 사업연도 기간을 지원해야 하며, 기간별로 세율·한도 등이 달라질 수 있음을 고려해야 한다.

3. **한도 계산 모듈**: 접대비 한도, 감가상각 한도, 업무용승용차 비용 한도 등 세법상 다양한 한도 계산이 필요하다. 한도 유형별로 계산 로직을 모듈화하는 것이 좋다.

4. **유보·사외유출 추적**: 세무조정 항목은 **유보(Reserve)**와 **사외유출(Outflow)** 구분이 중요하다. 유보는 일시적 차이로 향후 역전되며, 사외유출은 영구적 차이다. 이를 추적하는 소득처분(Income Disposition) 관리 기능이 필요하다.

5. **법인세-종합소득세 통합**: 동일 시스템에서 개인사업자와 법인사업자를 모두 처리해야 한다면, 세금 계산 파이프라인의 공통 부분과 차별 부분을 명확히 분리하여 설계해야 한다.

### ERP·회계 프로그램 연동 시 참고 사항

- **세무조정 자동화**: 기업회계 결산 데이터를 받아 세무조정 항목을 자동 산출하는 것이 법인세 모듈의 핵심이다. 계정과목 코드(Account Code)와 세무조정 규칙의 매핑 테이블이 필요하다.
- **홈택스 법인세 전자신고**: 법인세 신고서 양식(서식 코드 체계)과 필드 매핑이 필요하다. 부속명세서가 다수 존재하므로 양식별 데이터 구조 관리가 중요하다.
- **감가상각 관리 시스템**: 자산별로 세법상 내용연수, 상각 방법, 전기 상각 누계액 등을 관리하여 한도 계산을 자동화해야 한다.
- **업무용승용차 관리**: 차량별 운행일지 데이터를 수집·관리하고, 업무사용 비율을 자동 계산하는 기능이 필요하다. 차량 관련 비용(유류비, 보험료, 수선비, 통행료 등)을 차량별로 집계하는 데이터 구조가 필요하다.
- **이월결손금 추적**: 과거 사업연도의 결손금을 연도별로 관리하고, 당기 공제 가능 금액을 자동 계산하는 기능이 필요하다 (15년 이월 한도 추적).

## 용어 사전 (Glossary)

| 한글 | 영문 | 설명 |
|------|------|------|
| 법인세 | Corporate Tax | 법인의 각 사업연도 소득에 대해 부과하는 세금 |
| 세무조정 | Tax Adjustment | 기업회계이익을 세무상 과세소득으로 전환하는 과정 |
| 익금산입 | Addition to Revenue | 회계상 수익이 아니지만 세법상 수익으로 추가 |
| 익금불산입 | Exclusion from Revenue | 회계상 수익이지만 세법상 수익에서 제외 |
| 손금불산입 | Disallowed Expenses | 회계상 비용이지만 세법상 비용으로 불인정 |
| 손금산입 | Addition to Expenses | 회계상 비용이 아니지만 세법상 비용으로 인정 |
| 사업연도 | Business Year / Fiscal Year | 법인세 과세 기간 (최대 1년) |

| 사외유출 | Outflow | 영구적 차이로 법인 외부에 유출된 세무조정 항목 |
