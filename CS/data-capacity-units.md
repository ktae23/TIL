## 기본 단위

### 비트 (Bit)
- 컴퓨터가 처리하는 **최소 단위**
- `0` 또는 `1` 두 가지 상태만 표현

### 바이트 (Byte)
- **8개의 비트** = 1 바이트
- 256가지 값 표현 가능 (0 ~ 255)

```
1 Byte = 8 bits = 00000000 ~ 11111111

예: 문자 'A' = 01000001 (ASCII 65)
    문자 'a' = 01100001 (ASCII 97)
```

## 용량 단위 체계

### 10진수 기반 (SI 단위) - 저장장치 제조사 사용

| 단위 | 기호 | 크기 | 바이트 |
|------|------|------|--------|
| 킬로바이트 | KB | 10³ | 1,000 |
| 메가바이트 | MB | 10⁶ | 1,000,000 |
| 기가바이트 | GB | 10⁹ | 1,000,000,000 |
| 테라바이트 | TB | 10¹² | 1,000,000,000,000 |
| 페타바이트 | PB | 10¹⁵ | 1,000,000,000,000,000 |

### 2진수 기반 (IEC 단위) - OS/메모리 표기

| 단위 | 기호 | 크기 | 바이트 |
|------|------|------|--------|
| 키비바이트 | KiB | 2¹⁰ | 1,024 |
| 메비바이트 | MiB | 2²⁰ | 1,048,576 |
| 기비바이트 | GiB | 2³⁰ | 1,073,741,824 |
| 테비바이트 | TiB | 2⁴⁰ | 1,099,511,627,776 |
| 페비바이트 | PiB | 2⁵⁰ | 1,125,899,906,842,624 |

## 10진수 vs 2진수 차이

### 왜 용량이 다르게 표시될까?

```
1TB HDD를 샀는데 왜 931GB로 표시될까?

제조사 표기:  1 TB = 1,000,000,000,000 bytes (10진수)
OS 표기:     ÷ 1,073,741,824 = 931.32 GiB (2진수)
```

### 단위별 차이 비교

| 단위 | SI (10진) | IEC (2진) | 차이 |
|------|-----------|-----------|------|
| KB/KiB | 1,000 | 1,024 | 2.4% |
| MB/MiB | 1,000,000 | 1,048,576 | 4.9% |
| GB/GiB | 10⁹ | 2³⁰ | **7.4%** |
| TB/TiB | 10¹² | 2⁴⁰ | **9.9%** |

## 비트 vs 바이트 (네트워크 vs 저장장치)

### 표기법 주의

| 구분 | 단위 | 표기 | 예시 |
|------|------|------|------|
| 네트워크 속도 | bits per second | **소문자 b** | 100 M**b**ps |
| 파일 크기 | Bytes | **대문자 B** | 100 M**B** |

### 실제 다운로드 속도 계산

```
인터넷 속도: 100 Mbps (Mega bits per second)

실제 다운로드 속도:
100 Mbps ÷ 8 = 12.5 MB/s

1GB 파일 다운로드 시간:
1,000 MB ÷ 12.5 MB/s = 80초
```

## 실생활 용량 예시

### 텍스트

| 항목 | 용량 |
|------|------|
| 영문자 1개 | 1 Byte (ASCII) |
| 한글 1글자 | 3 Bytes (UTF-8) |
| A4 문서 1장 | 2~5 KB |
| 소설 1권 | 500 KB ~ 1 MB |

### 이미지

| 항목 | 용량 |
|------|------|
| 아이콘 (32x32) | 1~5 KB |
| 스크린샷 | 100 KB ~ 1 MB |
| 스마트폰 사진 | 2~5 MB |
| RAW 이미지 | 20~50 MB |

### 오디오/비디오

| 항목 | 용량 |
|------|------|
| MP3 (1분) | 1 MB |
| FLAC 무손실 (1분) | 30 MB |
| YouTube 720p (1분) | 15~25 MB |
| YouTube 4K (1분) | 100~200 MB |
| 영화 1080p | 2~5 GB |
| 영화 4K | 20~50 GB |

## 2의 거듭제곱 암기

| 거듭제곱 | 값 | 의미 |
|----------|-----|------|
| 2⁸ | 256 | 1 Byte로 표현 가능한 값의 수 |
| 2¹⁰ | 1,024 | 1 KiB |
| 2²⁰ | 1,048,576 | 1 MiB |
| 2³⁰ | ≈ 10억 | 1 GiB |
| 2³² | ≈ 42억 | 32비트 주소 공간 (4GB) |
| 2⁶⁴ | ≈ 1844경 | 64비트 주소 공간 |
