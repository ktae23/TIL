# 벡터 PDF vs 래스터 PDF

## 개요

PDF는 내부적으로 벡터 그래픽과 래스터 이미지를 모두 담을 수 있다. 브라우저에서 HTML을 PDF로 변환할 때 어떤 방식을 선택하느냐에 따라 결과물의 품질과 활용도가 크게 달라진다.

## 근본적 차이

### 벡터 PDF

텍스트, 도형, 선 등을 **수학적 좌표와 명령어**로 기술한다.

```
PDF 내부 구조 (간략화):
BT                          % Begin Text
/F1 12 Tf                   % 폰트 F1, 12pt
100 700 Td                  % 좌표 (100, 700)으로 이동
(Hello World) Tj            % 텍스트 출력
ET                          % End Text
```

- 텍스트는 폰트 + 좌표 + 문자열로 저장
- 확대해도 깨지지 않음 (수학적 계산으로 재렌더링)
- 파일 크기가 콘텐츠 복잡도에 비례 (페이지 수에 선형)

### 래스터 PDF

HTML을 **픽셀 이미지(캔버스)로 캡처**한 뒤 PDF에 이미지로 삽입한다.

```
PDF 내부 구조 (간략화):
/Image1 Do                  % 이미지 객체 배치
  └─ JPEG 데이터 (1600×2263px, 95% quality)
```

- 전체 페이지가 하나의 JPEG/PNG 이미지
- 확대하면 픽셀이 보임 (고정 해상도)
- 파일 크기가 해상도의 제곱에 비례

## 비교표

| 항목 | 벡터 PDF | 래스터 PDF |
|------|---------|-----------|
| **생성 방식** | `window.print()`, Puppeteer | html2canvas + jsPDF |
| **텍스트 선택/복사** | 가능 | 불가 (이미지) |
| **검색 (Ctrl+F)** | 가능 | 불가 |
| **확대 품질** | 무한 확대 가능 | 픽셀 깨짐 (scale 의존) |
| **파일 크기** | 작음 (텍스트 기반) | 큼 (이미지 기반) |
| **폰트 렌더링** | 브라우저 네이티브 | 캔버스 래스터화 |
| **CSS 지원** | 완벽 (브라우저 엔진) | 부분적 (html2canvas 재구현) |
| **페이지 나눔** | CSS `page-break` 네이티브 | 캔버스 슬라이싱 (근사치) |
| **캔버스 크기 제한** | 없음 | 있음 (~16,384px) |
| **원클릭 다운로드** | 불가 (프린트 다이얼로그) | 가능 |
| **접근성 (스크린리더)** | 텍스트 인식 가능 | 불가 |

## 파일 크기 비교 (실측)

33페이지 한글 문서 기준:

| 방식 | 파일 크기 | 비고 |
|------|----------|------|
| window.print() (벡터) | ~500KB | 텍스트 + 폰트 서브셋 |
| html2pdf scale 1 (래스터) | ~3.6MB | 저해상도 JPEG × 33장 |
| html2pdf scale 2 (래스터) | 생성 실패 | 캔버스 높이 초과 |

## 확대 시 차이

```
벡터 PDF 200% 확대:
┌─────────────────────┐
│ 세무기장 도메인      │  ← 선명한 텍스트 (수학적 렌더링)
│ 기초 가이드          │
└─────────────────────┘

래스터 PDF 200% 확대:
┌─────────────────────┐
│ ▓▒░ 세무기장 ░▒▓    │  ← 픽셀 보임 (고정 해상도 이미지)
│ ▓▒░ 기초 가이 ░▒▓   │
└─────────────────────┘
```

## 태블릿 S펜 필기 용도에서의 차이

| 시나리오 | 벡터 | 래스터 |
|---------|------|--------|
| 핀치 줌으로 확대 후 필기 | 텍스트 선명 유지 | 텍스트 흐릿해짐 |
| 텍스트 위에 하이라이트 | 텍스트 레이어 위에 드로잉 | 이미지 위에 드로잉 (동일) |
| 텍스트 선택 후 메모 | 가능 | 불가 |
| 삼성노트 앱에서 텍스트 검색 | 가능 | 불가 |
| OCR 없이 텍스트 추출 | 가능 | 불가 |

## 언제 래스터를 선택하는가

래스터 방식이 적합한 경우:

- **원클릭 다운로드**가 필수 (프린트 다이얼로그 불가)
- **짧은 문서** (10페이지 이하, 캔버스 제한 내)
- **시각적 정확성**: CSS 그래디언트, 그림자 등 복잡한 시각 효과가 중요
- **서버리스 환경**: Puppeteer 없이 클라이언트에서 자동 다운로드 필요

## 결론

문서를 읽고 학습하는 용도라면 벡터 PDF가 압도적으로 유리하다. 텍스트 선택, 검색, 확대 품질, 파일 크기, 접근성 모든 면에서 우위. 프린트 다이얼로그 한 번 클릭하는 것이 유일한 트레이드오프다.
