## 도구

### /til - TIL 작성 스킬

Claude Code에서 `/til` 명령으로 새 학습 기록을 작성합니다.

- 카테고리 선택 (기존 또는 신규)
- 주제 및 내용 입력
- 마크다운 파일 자동 생성
- Git commit & push 자동화

### /til-viewer - TIL 뷰어 스킬

Claude Code에서 `/til-viewer` 명령으로 모든 TIL을 인터랙티브 웹 뷰어로 탐색합니다.

- 전체 파일 검색 (Ctrl+K)
- 다크/라이트 테마 지원
- 목차 자동 생성
